# 洛谷 B3616【模板】队列

## 题目来源

- 平台：洛谷
- 题号：B3616
- 原题链接：[B3616 【模板】队列](https://www.luogu.com.cn/problem/B3616)

## 题面

请你实现一个队列（queue），支持如下操作：

- `push(x)`：向队列中加入一个数 `x`。
- `pop()`：将队首弹出。如果此时队列为空，则不进行弹出操作，并输出 `ERR_CANNOT_POP`。
- `query()`：输出队首元素。如果此时队列为空，则输出 `ERR_CANNOT_QUERY`。
- `size()`：输出此时队列内元素个数。

输入格式：第一行一个整数 `n`，表示操作的次数。接下来 `n` 行，每行表示一个操作：

- `1 x`：将元素 `x` 加入队列；
- `2`：将队首弹出队列；
- `3`：查询队首；
- `4`：查询队列内元素个数。

输出格式：输出若干行，对于每个操作按题目描述输出结果。每条输出之间应当用空行隔开。

数据规模与约定：对于 `100%` 的测试数据，`n <= 10000`，且被插入队列的所有元素值是 `[1, 1000000]` 以内的正整数。

## 涉及知识点

- 队列（`queue`）：先进先出的线性结构。
- 用数组和队首、队尾两个下标实现队列。

## 难度评估

D（入门）：队列的模板实现，操作都是常数时间的下标移动，主要考察结构本身和空队列的边界输出。

## 解法一：数组加双下标

### 解题思路

用数组 `queue` 存数据，`l` 指向队首、`r` 指向队尾，队列中的元素就是区间 `[l, r]`：

- 初始时 `l = 0`、`r = -1`，区间为空；
- `push`：`r` 先右移，再写入 `queue[r]`，新元素进入队尾；
- `pop`：只把 `l` 右移，队首元素被排除在区间之外；
- `query`：返回 `queue[l]`，也就是最早进队的元素；
- `size`：返回 `r - l + 1`。

数组长度开到 `n + 10`：`n` 是操作次数，最坏情况下所有操作都是入队，所以容量必须按照可能的最大入队次数来准备，多开一点余量避免越界。

四个操作都是常数时间的下标移动，因此单次操作都是 `O(1)`。

### 复杂度分析

- 时间复杂度：每个操作都是 `O(1)`，`n` 次操作合计 `O(n)`。
- 额外空间复杂度：`O(n)`，需要一个容量为 `n + 10` 的数组；下标变量只有常数个。

### 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Queue {
    vector<int> queue;
    int l, r;

    Queue(int n) {
        queue.resize(n);
        // l 指向队首，r 指向队尾；r = l - 1 表示区间为空。
        l = 0, r = -1;
    }

    void push(int x) {
        // 尾指针先右移，再写入。
        queue[++r] = x;
    }

    void pop() {
        // 出队只移动队首下标，不搬动数据。
        l++;
    }

    int size() {
        return r - l + 1;
    }

    int query() {
        return queue[l];
    }
};

void solve() {
    int m;
    cin >> m;
    // 数组容量按操作次数准备，避免入队越界。
    Queue q(m + 10);
    while (m--) {
        int a, x;
        cin >> a;
        if (a == 1) {
            cin >> x;
            q.push(x);
        } else if (a == 2) {
            // 空队列不能弹出，按题目要求输出固定字符串。
            if (q.size() == 0)
                cout << "ERR_CANNOT_POP" << endl;
            else
                q.pop();
        } else if (a == 3) {
            if (q.size() == 0)
                cout << "ERR_CANNOT_QUERY" << endl;
            else
                cout << q.query() << endl;
        } else
            cout << q.size() << endl;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    solve();
    return 0;
}
```

### 坑点

- 两条错误信息必须与题目完全一致：`ERR_CANNOT_POP` 和 `ERR_CANNOT_QUERY`，写成别的字符串会判错。
- 数组容量要按可能的最大入队次数准备。代码里传入 `m + 10`，比操作次数还多一点余量；如果按“当前队列长度”开数组就会越界。
- `size()` 依赖 `r - l + 1`，初始 `r = l - 1` 恰好得到 0，所以不需要额外的计数器。
- 题面写了“每条输出之间应当用空行隔开”，raw 的模板用 `endl` 每行输出一个结果；洛谷的输出比较会忽略多余的空白，所以这个模板可以通过。
