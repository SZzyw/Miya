# 洛谷 P2249【深基13.例1】查找

## 题目来源

- 平台：洛谷
- 题号：P2249
- 原题链接：[P2249 【深基13.例1】查找](https://www.luogu.com.cn/problem/P2249)

## 题面

输入 `n` 个不超过 `10^9` 的单调不减的非负整数 `a_1, a_2, ..., a_n`，然后进行 `m` 次询问。

对于每次询问，给出一个整数 `q`，要求输出 `q` 在序列中第一次出现的编号；如果没有找到，输出 `-1`。题目中的编号从 1 开始。

### 输入格式

- 第一行输入两个整数 `n` 和 `m`，表示数字个数和询问次数。
- 第二行输入 `n` 个整数，表示待查询的有序序列。
- 第三行输入 `m` 个整数，表示查询的数字。

### 输出格式

输出一行 `m` 个整数，用空格分隔，表示每次查询的答案。

### 数据范围与提示

- `1 <= n <= 10^6`
- `0 <= a_i, q <= 10^9`
- `1 <= m <= 10^5`
- 输入输出量较大，需要使用较快的 IO 方式。

## 难度评估

D（入门）：题目是单调不减数组上的多次查询，核心是使用二分搜索找到第一个大于等于查询值的位置，再判断该位置的值是否等于查询值。

## 解题思路

对每个查询值 `x`，在单调不减数组中寻找第一个满足 `arr[i] >= x` 的位置：

- 如果 `arr[m] < x`，说明 `m` 及其左侧都不可能是答案，搜索区间向右移动。
- 如果 `arr[m] >= x`，`m` 是一个候选位置，但左侧可能还有更早的位置，因此记录 `m` 后继续向左搜索。

搜索结束后：

- 如果候选位置上的元素等于 `x`，它就是 `x` 第一次出现的位置；
- 如果候选位置上的元素大于 `x`，说明数组中没有 `x`。

由于数组下标从 0 开始，而题目编号从 1 开始，输出时需要将下标加 1。

## 复杂度分析

- 预处理数组：`O(n)`，用于读入 `n` 个元素。
- 单次查询：`O(log n)`，每次二分将候选区间缩小一半。
- 总时间复杂度：`O(n + m log n)`。
- 额外空间复杂度：`O(1)`，除存储输入数组外，二分只使用常数个变量。

## 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int findLeft(vector<int> &arr, int nums) {
    int l = 0;
    int r = arr.size() - 1;
    int ans = -1;

    while (l <= r) {
        int m = l + (r - l) / 2;

        if (arr[m] >= nums) {
            // 当前点满足条件，记录后继续向左寻找第一次出现的位置。
            ans = m;
            r = m - 1;
        } else {
            // m 及其左侧都小于 nums，只能向右搜索。
            l = m + 1;
        }
    }

    return ans;
}

void solve() {
    int n, m;
    cin >> n >> m;

    vector<int> arr(n);
    for (int i = 0; i < n; i++)
        cin >> arr[i];

    while (m--) {
        int x;
        cin >> x;

        int ans = findLeft(arr, x);
        if (arr[ans] == x)
            cout << ans + 1 << ' ';
        else
            cout << -1 << ' ';
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    solve();
    return 0;
}
```

## 坑点

- 题目要求输出第一次出现的位置，因此不能在找到任意一个等于 `x` 的位置后立即返回，必须继续向左寻找。
- 二分得到的是 0-based 下标，输出时要加 1。
- 题目数据量较大，代码使用了关闭同步和解除绑定的 IO 设置。
