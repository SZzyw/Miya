# 洛谷 B3642 二叉树的遍历

## 题目来源

- 平台：洛谷
- 题号：B3642
- 原题链接：[B3642 二叉树的遍历](https://www.luogu.com.cn/problem/B3642)

## 题面

有一棵包含 `n` 个节点的二叉树，节点编号为 `1` 到 `n`，根节点编号为 `1`。给出每个节点的左右子节点编号，编号 `0` 表示对应方向没有子节点。建立这棵二叉树后，依次求出它的前序、中序和后序遍历。

### 输入格式

- 第一行输入一个整数 `n`，表示节点数。
- 接下来 `n` 行，第 `i` 行输入两个整数，分别表示节点 `i` 的左子节点和右子节点编号；如果没有对应子节点，则输入 `0`。

### 输出格式

输出三行，每行包含 `n` 个节点编号，用空格隔开：

1. 第一行是前序遍历；
2. 第二行是中序遍历；
3. 第三行是后序遍历。

## 难度评估

D（入门）：题目直接给出每个节点的左右孩子关系，核心是按照三种遍历的访问时机递归访问整棵树。

## 解题思路

先把每个节点的左右孩子编号保存到 `tree[i]` 中，其中 `tree[i][0]` 是左孩子，`tree[i][1]` 是右孩子。三种遍历共享同一个递归框架，区别只有输出当前节点的时机：

- 先序：输出当前节点，再递归左子树和右子树，即“中 -> 左 -> 右”；
- 中序：递归左子树，输出当前节点，再递归右子树，即“左 -> 中 -> 右”；
- 后序：递归左子树和右子树，最后输出当前节点，即“左 -> 右 -> 中”。

当 `head == 0` 时，当前子树不存在，直接返回。根节点固定为 `1`，分别调用三个函数即可。

## 复杂度分析

每种遍历都会访问每个节点一次，因此单次遍历的时间复杂度为 `O(n)`。递归调用的最大深度等于二叉树高度，额外空间复杂度为 `O(h)`；其中 `h` 是树高。

## 解法一：递归遍历

### 解题思路

递归函数 `preOrder`、`inOrder` 和 `posOrder` 的参数 `head` 表示当前要处理的子树根节点编号。

- `head == 0` 是递归终止条件；
- 对于非空节点，按照目标遍历顺序安排“输出当前节点”和“递归左右子树”的相对位置；
- `solve` 读入节点关系后，从根节点 `1` 开始依次调用三个遍历函数。

### 复杂度分析

每个节点在每种遍历中只被递归进入一次，所以每种遍历的时间复杂度都是 `O(n)`。递归过程中系统栈最多保存从根到当前节点的一条路径，额外空间复杂度为 `O(h)`。

### 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using PII = array<int, 2>;
vector<PII> tree;

void preOrder(int head) {
    // 空节点编号为 0，递归到这里时结束当前分支。
    if (head == 0)
        return;

    // 先输出根，再递归左、右子树，对应“中 -> 左 -> 右”。
    cout << head << ' ';
    preOrder(tree[head][0]);
    preOrder(tree[head][1]);
}

void inOrder(int head) {
    // 空节点不参与遍历。
    if (head == 0)
        return;

    // 输出夹在左右递归之间，对应“左 -> 中 -> 右”。
    inOrder(tree[head][0]);
    cout << head << ' ';
    inOrder(tree[head][1]);
}

void posOrder(int head) {
    // 空节点不参与遍历。
    if (head == 0)
        return;

    // 左右子树都完成后再输出根，对应“左 -> 右 -> 中”。
    posOrder(tree[head][0]);
    posOrder(tree[head][1]);
    cout << head << ' ';
}

void solve() {
    int n;
    cin >> n;
    tree.resize(n + 1);

    // 第 i 行给出节点 i 的左右孩子；0 表示没有对应孩子。
    for (int i = 1; i <= n; i++) {
        int x, y;
        cin >> x >> y;
        tree[i] = {x, y};
    }

    // 根节点编号固定为 1，依次输出三种遍历。
    preOrder(1);
    cout << endl;
    inOrder(1);
    cout << endl;
    posOrder(1);
    cout << endl;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);

    int T = 1;
    // cin>>T;
    while (T--)
        solve();
    return 0;
}
```

### 坑点

- `tree[i][0]` 和 `tree[i][1]` 分别表示左、右子树，不能交换。
- `0` 是空子树编号，递归函数必须先判断 `head == 0`，不能继续访问 `tree[0]`。
- 三种遍历的代码结构相似，真正决定顺序的是输出语句相对于两次递归调用的位置。

## 解法二：使用栈模拟递归

### 解题思路

不使用系统递归时，用 `stack<int>` 保存尚未处理的节点和遍历过程中的状态。

- 先序遍历：节点第一次弹出时就访问，因此先输出当前节点。由于栈后进先出，要先压入右孩子，再压入左孩子。
- 中序遍历：按照递归思路先向左走，左侧完成后返回输出当前节点，再处理右子树。代码通过压入“右子树、当前节点、左子树”来模拟这个过程。
- 后序遍历：当前节点必须等左右子树都处理完成后才能输出。代码用 `head` 记录上次打印的节点，根据它来自当前节点的左子树还是右子树，决定继续进入右子树还是弹出当前节点。

### 复杂度分析

三种栈遍历都只处理每个节点常数次，因此时间复杂度为 `O(n)`。栈中保存的待处理节点数量与树高同阶，额外空间复杂度为 `O(h)`。

### 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using PII = array<int, 2>;
vector<PII> tree;

void preOrder(int head) {
    stack<int> s;
    s.push(head);

    while (s.size()) {
        // 弹出当前要访问的节点，并立即输出根节点。
        head = s.top();
        s.pop();
        cout << head << " ";

        // 右孩子先入栈、左孩子后入栈，保证左孩子先出栈。
        if (tree[head][1] != 0)
            s.push(tree[head][1]);
        if (tree[head][0] != 0)
            s.push(tree[head][0]);
    }
}

void inOrder(int head) {
    stack<int> s;
    s.push(head);

    while (s.size()) {
        head = s.top();
        s.pop();

        if (head == 0) {
            // 空节点表示左边界走到尽头；弹出并输出对应的根节点。
            if (s.size()) {
                cout << s.top() << ' ';
                s.pop();
            }
            continue;
        }

        // 压入右子树、当前节点和左子树，借助后进先出模拟左根右。
        s.push(tree[head][1]);
        s.push(head);
        s.push(tree[head][0]);
    }
}

void posOrder(int head) {
    stack<int> s;
    s.push(head);

    while (s.size()) {
        int cur = s.top();

        // 第一次到达节点时先深入左子树；head 用于判断上次完成的是哪棵子树。
        if (tree[cur][0] != 0 && head != tree[cur][0] && head != tree[cur][1])
            s.push(tree[cur][0]);
        // 左子树完成后转向右子树。
        else if (tree[cur][1] != 0 && head != tree[cur][1])
            s.push(tree[cur][1]);
        else {
            // 左右子树均处理完毕，输出当前节点并记录为上次完成的节点。
            cout << cur << ' ';
            head = cur;
            s.pop();
        }
    }
}

void solve() {
    int n;
    cin >> n;
    tree.resize(n + 5);

    // 读入每个节点的左右孩子关系。
    for (int i = 1; i <= n; i++) {
        int x, y;
        cin >> x >> y;
        tree[i] = {x, y};
    }

    // 根节点编号固定为 1，依次调用三种非递归遍历。
    preOrder(1);
    cout << endl;
    inOrder(1);
    cout << endl;
    posOrder(1);
    cout << endl;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);

    int T = 1;
    // cin>>T;
    while (T--)
        solve();
    return 0;
}
```

### 坑点

- 先序栈实现中必须右孩子先入栈、左孩子后入栈，否则访问顺序会变成“根右左”。
- 中序栈实现依赖空节点 `0` 作为返回标记，不能删除 `head == 0` 分支。
- 后序栈实现依赖 `head` 保存上次打印的节点；如果不区分左子树和右子树是否完成，就无法判断当前节点能否输出。
