# 洛谷 P4305 [JLOI2011] 不重复数字

## 题目来源

- 平台：洛谷
- 题号：P4305
- 原题链接：[P4305 [JLOI2011] 不重复数字](https://www.luogu.com.cn/problem/P4305)

## 题面

给定 `n` 个数，要求把其中重复的去掉，只保留第一次出现的数。

输入格式：本题有多组数据。第一行一个整数 `T`，表示数据组数。对于每组数据：第一行一个整数 `n`；第二行 `n` 个数，表示给定的数。

输出格式：对于每组数据，输出一行，为去重后剩下的数，两个数之间用一个空格隔开。

数据范围：对于 `30%` 的数据，`n <= 100`，给出的数在 `[0, 100]`；对于 `60%` 的数据，`n <= 10^4`，给出的数在 `[0, 10^4]`；对于 `100%` 的数据，`1 <= T <= 50`，`1 <= n <= 5 * 10^4`，给出的数在 `32` 位有符号整数范围内。

## 涉及知识点

- 哈希（`hash`）：把大范围的取值映射到小范围的数组下标，并处理哈希冲突。
- 开放寻址法与拉链法两种冲突处理方式。

## 难度评估

C（基础）：题目本身只是去重，难点在于不能用 `vis` 之类的大数组直接标记（取值范围是整个 32 位有符号整数范围），必须手写哈希表；两种冲突处理方式都值得掌握。

## 解法一：开放寻址法

### 解题思路

用两个长度为 `n` 的数组：`arr` 存数值，`vis` 标记该位置是否已经放过元素。

- 落点计算：`t = (x % n + n) % n`。先取模再加 `n` 再取模，是为了让负数也能落回 `[0, n)`。
- `find(x)`：从 `t` 出发，只要当前位置“不是 `x` 且已被占用”，就往后探测 `(t + 1) % n`。循环停下来时，要么当前位置就是 `x`，要么当前位置是空位，所以 `find` 同时承担了“查重”和“找可写入位置”两个职责。
- `insert(x)`：先 `find` 出落点，如果该位置是空的就写入并标记，返回 `true`；否则说明 `x` 已经出现过，返回 `false`。

主程序按输入顺序读入每个数，`insert` 返回 `true` 时才输出，于是输出的就是每个数第一次出现的位置，天然满足“只保留第一次出现的数”。

表长取 `n` 是够用的：一组数据里最多只有 `n` 个不同的数，写入 `n - 1` 个不同值之后仍会剩下一个空位供最后一个数落点，不会出现找不到空位的情况。

### 复杂度分析

- 时间复杂度：期望 `O(n)`。散列均匀时，每次插入和查找的平均探测次数是常数，整组数据是线性的。最坏情况下（大量不同的数落到同一个起始位置、连续探测）单组会退化到 `O(n^2)`，但需要刻意构造才有机会触发。
- 额外空间复杂度：`O(n)`，`arr` 和 `vis` 各占 `n` 个位置。

### 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Hash_table {
    vector<int> arr;
    vector<bool> vis;

    Hash_table(int n) {
        arr.assign(n, 0);
        vis.assign(n, false);
    }

    int find(int x) {
        int n = arr.size();
        // 负数也要落到 [0, n)：先取模再加 n 再取模。
        int t = (x % n + n) % n;
        // 当前位置不是 x 且已被占用就继续向后探测。
        while (arr[t] != x && vis[t] == true) {
            t = (t + 1) % n;
        }
        return t;
    }

    bool insert(int x) {
        int pos = find(x);
        // 落点是空位说明第一次出现，写入并返回 true。
        if (vis[pos] == false) {
            arr[pos] = x;
            vis[pos] = true;
            return true;
        }
        // 落点已经存着 x，说明重复。
        return false;
    }
};

void solve() {
    int n;
    cin >> n;
    Hash_table t(n);
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (t.insert(x))
            cout << x << ' ';
    }
    cout << endl;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);
    int T;
    cin >> T;
    // 多组数据，每组重新建一张表。
    while (T--)
        solve();
    return 0;
}
```

### 坑点

- 表长要按这组数据的元素个数 `n` 来开，并且每组数据都要重新建表；沿用上一组的表会把上一组的数据误判成重复。
- 判重必须同时看 `arr` 和 `vis`：空位置的 `arr` 是初始化的 `0`，只看 `arr` 会把真正插入过的 `0` 和空位混淆。
- `find` 只有在遇到空位或找到 `x` 时才会停。如果表被填满且里面没有 `x`，循环会一直转，所以表长不能小于可能的不同元素个数。
- 负数的取模在 C++ 里会得到负数，必须用 `(x % n + n) % n` 换算。

## 解法二：拉链法

### 解题思路

拉链法同样先算出起始位置 `t = (x % n + n) % n`，但冲突的元素不再向后探测，而是挂在同一个位置形成一条链。

- `head` 数组的每个位置存放这条链的头，用 `next == -1` 表示链空；
- 链上的节点存放在 `arr` 里，每个节点记录 `val` 和 `next`，用数组模拟链表，避免频繁申请节点；
- `find(x)`：从 `head[t].next` 开始沿链比较，找到就返回 `x`，走完整条链说明不存在，返回 `-1`；
- `insert(x)`：先 `find`，如果返回 `-1`，就把新节点头插到这条链上：`arr.push_back(Node(x, head[t].next))`，再把 `head[t].next` 指向新节点。

### 复杂度分析

- 时间复杂度：期望 `O(n)`。散列均匀时每条链的平均长度是常数，插入和查找都是常数时间的链上比较；最坏情况（所有元素都落在同一个位置）退化为 `O(n^2)`。
- 额外空间复杂度：`O(n)`。`head` 占 `n` 个位置，`arr` 中的节点数不超过插入的不同元素个数。

### 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int val;
    int next;

    Node(int val = -1, int next = -1) : val(val), next(next) {
    }
};

struct ChainedHashTable {
    vector<Node> arr, head;

    ChainedHashTable(int n) : head(n) {
        // head 的每个位置是一条链的头，next = -1 表示链空。
        head.assign(n, Node());
        arr.clear();
    }

    int find(int x) {
        int n = head.size();
        int t = (x % n + n) % n;
        // 沿链逐个比较，找到返回 x，走完整条链返回 -1。
        for (int i = head[t].next; i != -1; i = arr[i].next) {
            int val = arr[i].val;
            if (val == x)
                return x;
        }
        return -1;
    }

    bool insert(int x) {
        int pos = find(x);
        int n = head.size();
        int t = (x % n + n) % n;
        if (pos == -1) {
            // 头插：新节点的 next 指向原来的链头。
            arr.push_back(Node(x, head[t].next));
            head[t].next = arr.size() - 1;
            return true;
        }
        return false;
    }
};

void solve() {
    int n;
    cin >> n;
    ChainedHashTable ct(n);
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (ct.insert(x))
            cout << x << ' ';
    }
    cout << endl;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);
    int T;
    cin >> T;
    // 多组数据，每组重新建表。
    while (T--)
        solve();
    return 0;
}
```

### 坑点

- `find` 的返回值有两种含义：找到时返回的是 `x` 本身，找不到时返回 `-1`。因为题目里的数可以是任意 32 位有符号整数，所以不能想当然地用“返回下标”来判断。
- `head` 里的节点是哨兵，真正的元素从 `head[t].next` 开始；遍历的起点写成 `head[t]` 会把哨兵也当成数据。
- 用 `arr.push_back` 之后，新节点的下标是 `arr.size() - 1`，必须在这个位置更新 `head[t].next`，否则新节点不在链上。
- 每组数据都要重新构造 `ChainedHashTable`，`arr.clear()` 在构造函数里已经做掉了。
