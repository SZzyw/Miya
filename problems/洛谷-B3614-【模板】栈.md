# 洛谷 B3614【模板】栈

## 题目来源

- 平台：洛谷
- 题号：B3614
- 原题链接：[B3614 【模板】栈](https://www.luogu.com.cn/problem/B3614)

## 题面

请你实现一个栈（stack），支持如下操作：

- `push(x)`：向栈中加入一个数 `x`。
- `pop()`：将栈顶弹出。如果此时栈为空则不进行弹出操作，输出 `Empty`。
- `query()`：输出栈顶元素，如果此时栈为空则输出 `Anguei!`。
- `size()`：输出此时栈内元素个数。

输入格式：本题单测试点内有多组数据。输入第一行是一个整数 `T`，表示数据组数。对于每组数据，第一行是一个整数，表示操作的次数 `n`；接下来 `n` 行，每行首先是一个字符串，为 `push`、`pop`、`query`、`size` 之一。若为 `push`，则其后有一个整数 `x`。

输出格式：对于每组数据，按照题目描述中的要求依次输出，每次输出占一行。

数据规模与约定：`1 <= T, n <= 10^6`，且单个测试点内 `n` 之和不超过 `10^6`，即 `sum(n) <= 10^6`；保证 `0 <= x < 2^64`。

提示：请注意大量数据读入对程序效率造成的影响；输出的 `Empty` 不含叹号，`Anguei!` 含有叹号。

## 涉及知识点

- 栈（`stack`）：后进先出的线性结构。
- 用 `vector` 的尾部操作实现栈。

## 难度评估

D（入门）：栈的模板实现，逻辑只有同一端的进出；需要注意数据规模带来的读入效率和 `unsigned long long` 的取值范围。

## 解法一：用 vector 模拟栈

### 解题思路

栈的所有插入和删除都发生在同一端，而 `vector` 的 `push_back` 和 `pop_back` 正好作用在末尾，所以直接用 `vector` 当栈即可：

- `push`：`stack.push_back(x)`；
- `pop`：`stack.pop_back()`；
- `query`：`stack.back()` 取栈顶；
- `size`：`stack.size()`。

只有 `pop` 和 `query` 需要额外判断空栈，并输出题目指定的字符串。

因为元素满足 `0 <= x < 2^64`，超出了 `long long` 的表示范围，所以模板用 `#define int unsigned long long` 把整型统一换成 64 位无符号整数；用了这个宏之后入口必须写成 `signed main()`，否则 `int main` 会被替换成非法的类型名。

数据方面，`n` 之和可以达到 `10^6`，所以模板关闭了同步流并解除了 `cin`、`cout` 的绑定，减少大量读入的开销。

### 复杂度分析

- 时间复杂度：`push`、`pop`、`query`、`size` 都是均摊 `O(1)`（`vector` 的 `push_back` 在扩容时单次较慢，均摊后仍是常数）；所有数据合计 `O(sum(n))`。
- 额外空间复杂度：`O(n)`，栈本身最多存下当前这组数据的全部元素；此外每行读入的字符串是常数长度。

### 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int unsigned long long

struct Stack {
    vector<int> stack;

    void push(int x) {
        stack.push_back(x);
    }

    void pop() {
        stack.pop_back();
    }

    int query() {
        return stack.back();
    }

    int size() {
        return stack.size();
    }
};

void solve() {
    int m;
    cin >> m;
    Stack s;
    while (m--) {
        string a;
        int x;
        cin >> a;
        if (a == "push") {
            cin >> x;
            s.push(x);
        } else if (a == "pop") {
            // 空栈不能弹出，按题目要求输出不带叹号的 Empty。
            if (s.size() == 0)
                cout << "Empty" << endl;
            else
                s.pop();
        } else if (a == "query") {
            // 空栈查询输出 Anguei!，注意这里带叹号。
            if (s.size() == 0)
                cout << "Anguei!" << endl;
            else
                cout << s.query() << endl;
        } else
            cout << s.size() << endl;
    }
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int T = 1;
    cin >> T;
    // 每组数据重新构造一个空栈。
    while (T--)
        solve();
    return 0;
}
```

### 坑点

- 元素范围是 `0 <= x < 2^64`，`int` 和 `long long` 都装不下，必须用 `unsigned long long`。模板用宏统一替换，因此入口必须写 `signed main()`。
- `Empty` 不带叹号，`Anguei!` 带叹号，两个字符串必须逐字符一致。
- 本题是多组数据，每组都要用一个全新的空栈；把栈定义在 `solve()` 内部正好满足这一点。
- 数据量很大，读入字符串和整数都很频繁，需要关闭同步流加速，否则容易超时。
- 使用了 `#define int unsigned long long` 之后，`T`、`n` 等变量也都是无符号整数；模板里 `while (T--)` 的写法在 `T` 大于 0 时正常结束，因为判断用的是自减前的那一刻的值。
