# LeetCode 162：寻找峰值

## 题目来源

- 平台：LeetCode
- 题号：162
- 原题链接：[寻找峰值](https://leetcode.cn/problems/find-peak-element/)

## 题面

给定一个下标从 0 开始的整数数组 nums，找到任意一个峰值并返回它的下标。

如果一个元素严格大于它相邻的元素，那么这个元素就是峰值。数组两端之外的元素视为负无穷，因此第一个和最后一个元素也可能成为峰值。题目保证相邻元素不相等，并要求使用 O(log n) 的算法。

## 知识点

- 精确标签：二分搜索
- 关联知识页：[[算法讲解006【入门】二分搜索]]

## 难度评估

D（入门）：题目不要求数组整体有序，重点是理解“沿着上坡方向一定能找到峰值”，并据此排除一半区间。

## 解题思路

这道题的数组整体没有排序，不能直接套用“比较中点和目标值”的普通二分模板。这里利用的是另一种二分思想：只要能判断某一侧一定存在峰值，就可以舍弃另一侧。

### 1. 先处理数组两端

数组两端之外的元素视为负无穷，因此两端也可能是峰值。代码先处理这几种情况：

1. 数组只有一个元素时，唯一元素就是峰值，返回 0。
2. 如果 `nums[0] > nums[1]`，那么下标 0 左侧是负无穷，右侧又更小，所以 0 是峰值。
3. 如果 `nums[n] > nums[n - 1]`，那么下标 `n` 右侧是负无穷，左侧又更小，所以 `n` 是峰值。

如果以上情况都不成立，说明：

- `nums[0] < nums[1]`，从左端进入内部区间时是上坡；
- `nums[n - 1] < nums[n - 2]`，从内部区间走向右端时是下坡。

因此，内部区间 `[1, n - 1]` 的左边是上坡起点，右边是下坡终点，中间一定会出现一个由上坡转为下坡的位置，也就是峰值。

### 2. 根据中点附近的走势缩小范围

设当前检查位置为 `m`。

#### 情况一：`m` 本身是峰值

如果：

```text
arr[m] > arr[m - 1] 且 arr[m] > arr[m + 1]
```

那么 `m` 已经满足峰值定义，可以直接返回。

#### 情况二：左邻居大于当前值

如果 `arr[m - 1] > arr[m]`，说明从 `m - 1` 走向 `m` 时正在下降。此时向左寻找一定不会丢失答案：

- 如果继续向左是上升趋势，那么上升和当前下降之间必然有一个峰值；
- 如果向左途中再次下降，那么第一次由上升转为下降的位置就是峰值。

所以可以舍弃 `m` 及其右侧，将搜索区间改为 `[l, m - 1]`。

#### 情况三：右邻居大于当前值

如果没有进入上一个分支，结合题目保证相邻元素不相等，可知 `arr[m] > arr[m - 1]`。又因为 `m` 不是峰值，所以必然有 `arr[m + 1] > arr[m]`。

这说明当前点向右仍在上升，继续向右寻找一定能遇到峰值。因此可以舍弃 `m` 及其左侧，将搜索区间改为 `[m + 1, r]`。

每次判断都能保留一个必然包含峰值的区间，同时舍弃大约一半位置，这就是二分搜索能够成立的原因。

### 3. 为什么最后返回 `l`

`exist` 开始时只搜索内部区间，并且两端已经保证了“左侧上坡、右侧下坡”的结构。每次移动边界时，这个结构仍然保持：

- 向左移动时，新的右边界满足下降关系；
- 向右移动时，新的左边界满足上升关系。

当区间缩小到最后一个候选位置时，这个位置就是峰值。代码在循环结束后返回 `l`，即返回收缩后保留下来的位置。

## 复杂度分析

- 时间复杂度：`O(log n)`。每次循环都将当前搜索区间缩小到左半部分或右半部分。
- 额外空间复杂度：`O(1)`。只使用了几个下标变量，没有随着数组规模增长的辅助结构。

## 教练代码

```cpp
class Solution {
public:
    // 在已经排除两端峰值的前提下，在内部区间中二分寻找峰值。
    int exist(vector<int> &arr) {
        // 两端由 findPeakElement 提前处理，因此这里可以安全访问 m - 1 和 m + 1。
        int l = 1;
        int r = arr.size() - 2;

        while (l <= r) {
            // 当前仍可能包含峰值的区间为 [l, r]。
            int m = l + (r - l) / 2;

            if (arr[m] > arr[m - 1] && arr[m] > arr[m + 1]) {
                // 中点严格大于左右邻居，已经找到一个峰值。
                return m;
            }

            if (arr[m - 1] > arr[m]) {
                // 当前点左侧出现下降，峰值仍然可能在左半区。
                r = m - 1;
            } else {
                // 相邻元素不相等，未向左时说明右侧仍在上升，峰值在右半区。
                l = m + 1;
            }
        }

        // 搜索区间收缩后的候选位置就是峰值。
        return l;
    }

    // 先处理两个端点，再在内部区间中使用二分查找。
    int findPeakElement(vector<int>& nums) {
        int n = nums.size() - 1;

        if (nums.size() == 1 || nums[0] > nums[1]) {
            // 数组只有一个元素，或第一个元素大于右邻居时，0 是峰值。
            return 0;
        }

        if (nums[n] > nums[n - 1]) {
            // 最后一个元素右侧是负无穷，且它大于左邻居时，n 是峰值。
            return n;
        }

        // 两端都不是峰值，峰值一定在内部区间 [1, n - 1] 中。
        return exist(nums);
    }
};
```

## 代码中的关键点与坑

- 这份代码依赖题目的条件：相邻元素不相等，数组两端之外视为负无穷。
- `exist` 只处理内部区间；两端峰值由 `findPeakElement` 先判断。
- `exist` 中访问了 `arr[m - 1]` 和 `arr[m + 1]`，因此不能脱离端点判断单独调用。
- `arr[m - 1] > arr[m]` 时向左，其他情况向右，是因为只要沿着上坡方向走，就一定能遇到峰值。
- 返回的是任意一个峰值，不需要寻找下标最小的峰值。
