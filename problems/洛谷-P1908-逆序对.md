# 洛谷 P1908 逆序对

## 题目来源

- 平台：洛谷
- 题号：P1908
- 原题链接：[P1908 逆序对](https://www.luogu.com.cn/problem/P1908)

## 题面

给定一段正整数序列，如果下标对满足 `i < j` 且 `a[i] > a[j]`，那么这两个位置构成一个逆序对。请统计整个序列中的逆序对数量。

### 输入格式

- 第一行输入一个整数 `n`，表示序列长度；
- 第二行输入 `n` 个整数，表示给定序列；
- 序列中的每个数字不超过 `10^9`。

### 输出格式

输出序列中逆序对的数量。

### 数据范围

- `1 <= n <= 5 * 10^5`；
- 部分分值：`n <= 2500`、`n <= 4 * 10^4`。

## 难度评估

C（基础）：需要在归并排序的有序合并过程中统计逆序对；数据规模达到 `5 * 10^5`，不能使用 `O(n^2)` 的直接枚举。

## 解法：归并分治

### 解题思路

对于当前下标区间 `[l, r]`，逆序对可以拆成三类：

1. 左区间 `[l, m]` 内部的逆序对；
2. 右区间 `[m + 1, r]` 内部的逆序对；
3. 一个下标在左区间、另一个下标在右区间的跨区间逆序对。

前两类递归解决，第三类在 `merge` 中统计。由于左区间的下标天然小于右区间的下标，跨区间时只需要判断左值是否严格大于右值。

归并开始前，左右两个区间已经分别有序。代码中的 `sum` 表示已经从右区间取出的元素数量：

- 当当前右值更小时，先取出右值，并执行 `sum++`；这些右侧元素都比之后仍待处理的某些左侧元素小；
- 当当前左值 `arr[i]` 不大于右值 `arr[j]` 时，已经取出的 `sum` 个右侧元素都严格小于 `arr[i]`，因此把 `sum` 加入答案；
- 当左右元素相等时走左侧分支，不会把相等元素计入逆序对，符合题目要求的严格不等式 `a[i] > a[j]`；
- 合并过程同时把结果写入 `help`，再回写 `arr`，保证上层递归继续拥有有序的左右区间。

所以递归函数返回：

```text
左区间逆序对数量
+ 右区间逆序对数量
+ merge 统计的跨区间逆序对数量
```

任意逆序对恰好属于这三类中的一类，因此统计既不会重复，也不会遗漏。

### 正确性要点

在 `merge` 过程中，左右区间都保持有序。当左指针当前值不大于右指针当前值时，右区间中已经被取出的元素都小于当前左值：它们的下标在右侧、数值又更小，分别与当前左值构成一个跨区间逆序对。因此可以一次性加入 `sum`，而不必逐个枚举。

如果当前右值更小，则它先被取出并计入 `sum`；后续遇到足够大的左值时，再统一结算它的贡献。相等时优先取左值，确保严格大于条件不会把相等对算进去。

### 复杂度分析

每次 `merge` 对当前区间进行一次线性扫描。递归深度为 `O(log n)`，每一层所有合并过程合计处理 `O(n)` 个元素，因此：

- 时间复杂度：`O(n log n)`；
- `help` 辅助数组空间：`O(n)`；
- 递归栈空间：`O(log n)`；
- 完整代码额外空间：`O(n)`。

### 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long

struct ReversePairs {
    vector<int> &arr, help;

    ReversePairs(vector<int> &arr) : arr(arr) {
        // 辅助数组供每次 merge 写入有序结果。
        help.resize(arr.size());
    }

    int merge(int l, int m, int r) {
        int ans = 0, sum = 0;

        // 在合并有序左右区间的同时，统计跨越分界线的逆序对。
        for (int k = l, i = l, j = m + 1; k <= r; k++) {
            if (j == r + 1 || (i <= m && arr[i] <= arr[j])) {
                // 右侧已取出的元素都严格小于当前左值，数量为 sum。
                ans += sum;
                help[k] = arr[i];
                i++;
            } else {
                // 当前右值更小，先记入 sum，等待后续左值统一结算贡献。
                sum++;
                help[k] = arr[j];
                j++;
            }
        }

        // 回写有序结果，否则更高层 merge 无法使用左右有序这一前提。
        for (int i = l; i <= r; i++) {
            arr[i] = help[i];
        }
        return ans;
    }

    int reversePairs(int l, int r) {
        // 单元素区间不存在逆序对。
        if (l == r)
            return 0;

        // 先统计左右内部逆序对，再补上跨越左右分界线的部分。
        int m = l + (r - l) / 2;
        return reversePairs(l, m) + reversePairs(m + 1, r) + merge(l, m, r);
    }
};

vector<int> nums;

void solve() {
    int n;
    cin >> n;
    nums.resize(n);
    for (int i = 0; i < n; i++)
        cin >> nums[i];

    ReversePairs reverse_pairs(nums);
    cout << reverse_pairs.reversePairs(0, nums.size() - 1);
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);
    int T = 1;
    // cin>>T;
    while (T--)
        solve();
    return 0;
}
```

### 坑点

- 逆序对要求严格 `a[i] > a[j]`；相等时必须优先取左侧元素，不能计数。
- `sum` 统计的是已经取出的右侧元素**数量**，不是右侧元素之和；这与小和题中的 `sum` 含义不同。
- 统计跨区间逆序对后仍必须完成有序合并并回写原数组，否则上层递归的合并前提不成立。
- 题目保证 `n >= 1`，与这份代码使用 `l == r` 的递归终止条件相匹配。
- 逆序对数量最多为数量级 `n^2`，代码通过 `#define int long long` 使用 64 位整数保存答案。
