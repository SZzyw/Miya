# 洛谷 B4324【模板】双向链表

## 题目来源

原题链接：[洛谷 B4324【模板】双向链表](https://www.luogu.com.cn/problem/B4324)

## 题面

给出初始按编号排列的双向链表，支持将节点插入目标节点左侧或右侧、删除节点，操作结束后从左到右输出；空链表输出 Empty!。

## 难度评估

D（入门/基础）：核心是维护链表节点之间的连接关系。

## 解题思路

使用节点的 `next` 或 `pre` 记录连接。插入时先保存原连接，再同时修改受影响的相邻节点；删除时让删除节点两侧直接相连。

## 复杂度分析

单次链表操作只修改常数个连接，时间复杂度为 $O(1)$；遍历链表为 $O(n)$，额外空间取决于保存节点的方式。

## 教练代码

```cpp
#include <bits/stdc++.h>  
using namespace std;  
const int N = 1e6 + 10;  
  
struct Node {  
    int val;  
    int pre;  
    int next;  
  
    Node(int val = -1, int pre = -1, int next = -1) : val(val), pre(pre), next(next) {  
    }};  
  
vector<Node> arr;  
vector<int> fin;  
  
void init() {  
    // 0 号节点是哨兵；空链表时它的前驱和后继都指向自己。
    arr.push_back(Node(0, 0, 0));  
}  
  
void insertLeft(int x, int y) {  
    // 节点不能插到自己左侧；保留教练代码的边界处理。
    if (x == y)  
        return;  

    // 找到 x 的前驱，再把新节点插入“前驱”和 x 之间。
    x = fin[x];  
    x = arr[x].pre;  
    int z = arr[x].next;  
    fin[y] = arr.size();  
    arr.push_back(Node(y, x, z));  

    // 新节点同时接入前后两个方向，双链表的连接必须保持一致。
    arr[z].pre = arr.size() - 1;  
    arr[x].next = arr.size() - 1;  
}  
  
void insert(int x, int y) {  
    // 节点不能插到自己右侧；保留教练代码的边界处理。
    if (x == y)  
        return;  

    // 保存 x 原来的后继，把新节点放在 x 和 z 之间。
    x = fin[x];  
    int z = arr[x].next;  
    fin[y] = arr.size();  
    arr.push_back(Node(y, x, z));  

    // 同时修改 z 的前驱和 x 的后继，完成双向连接。
    arr[z].pre = arr.size() - 1;  
    arr[x].next = arr.size() - 1;  
}  
  
void erase(int x) {  
    // 已删除节点的映射为 -1，重复删除时直接忽略。
    if (fin[x] == -1)  
        return;  
    x = fin[x];  
    int y = x;  
    x = arr[x].pre;  
    int z = arr[y].next;  

    // 让待删除节点两侧直接相连，并维护 next 与 pre 两个方向。
    arr[x].next = z;  
    arr[z].pre = x;  
    fin[arr[y].val] = -1; // 删除后清除元素编号到节点下标的映射。  
}  
  
void solve() {  
    int n, m;  
    cin >> n >> m;  
    // fin 按元素编号开空间；后续用 fin[y] = arr.size() 直接写入映射。
    fin.resize(n + 5);  
    init();  

    // 依次把 1 到 n 插到前一个元素右侧，建立初始链表。
    for (int i = 1; i <= n; i++) {  
        insert(i - 1, i);  
    }  
    while (m--) {  
        int a, x, y;  
        cin >> a;  
        if (a == 1) {  
            cin >> x >> y;  
            // 先摘下 x，再插到 y 的左侧。
            erase(x);  
            insertLeft(y, x);  
        } else if (a == 2) {  
            cin >> x >> y;  
            // 先摘下 x，再插到 y 的右侧。
            erase(x);  
            insert(y, x);  
        } else {  
            cin >> x;  
            erase(x);  
        }  
    }  
    int i = arr[0].next;  
    if (i == 0) {  
        // 哨兵直接指向自己，说明所有元素都已删除。
        cout << "Empty!";  
        return;  
    }  
    // 从哨兵的后继开始，沿 next 输出链表中的有效节点。
    while (i != 0) {  
        cout << arr[i].val << " ";  
        i = arr[i].next;  
    }  
}  
  
int main() {  
    ios::sync_with_stdio(false);  
    cin.tie(NULL);  
    cout.tie(NULL);  
    solve();  
    return 0;  
}
```

## 坑点

- 插入和删除必须同时维护 `pre` 与 `next`。
- `fin.resize(n + 5)` 只是为元素编号分配映射空间；本代码随后使用 `fin[y] = arr.size()` 直接写入映射，并没有对 `fin` 使用 `push_back`，因此不存在“`resize` 后再 `push_back` 导致映射错位”的问题。
- `fin` 的默认值是 `0`，而 0 号节点正好是哨兵；这意味着如果访问未初始化或已删除的编号，可能误把它当作哨兵。按题目保证只对当前有效节点操作时没有影响；若题目不提供这种保证，才需要额外的有效性判断。
