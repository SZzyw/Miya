# 洛谷 P3378【模板】堆

## 题目来源

- 平台：洛谷
- 题号：P3378
- 原题链接：[P3378 【模板】堆](https://www.luogu.com.cn/problem/P3378)

## 题面

给定一个数列，初始为空，请支持下面三种操作：

1. 给定一个整数 `x`，请将 `x` 加入到数列中；
2. 输出数列中最小的数；
3. 删除数列中最小的数（如果有多个数最小，只删除 `1` 个）。

输入格式：第一行是一个整数，表示操作的次数 `n`。接下来 `n` 行，每行表示一次操作，首先有一个整数 `op` 表示操作类型：

- 若 `op = 1`，则后面有一个整数 `x`，表示要将 `x` 加入数列；
- 若 `op = 2`，则表示要求输出数列中的最小数；
- 若 `op = 3`，则表示删除数列中的最小数。如果有多个数最小，只删除 `1` 个。

输出格式：对于每个操作 `2`，输出一行一个整数表示答案。

数据范围：对于 `30%` 的数据，`n <= 15`；对于 `70%` 的数据，`n <= 10^4`；对于 `100%` 的数据，`1 <= n <= 10^6`，`1 <= x < 2^31`，`op` 属于 `{1, 2, 3}`。

## 涉及知识点

- 堆（`heap`）：用完全二叉树维护最值的结构。
- 小根堆的向上调整与向下调整。

## 难度评估

D（入门）：堆的模板题，两种调整都是固定写法，只要注意这里是取最小值、要用小根堆即可。

## 解法一：手写小根堆

### 解题思路

题目要的是最小值，所以维护**小根堆**：每个节点都不大于它的两个孩子，堆顶 `arr[0]` 就是整个数列的最小值。堆用数组表示，下标 `i` 的父节点是 `(i - 1) / 2`，左孩子是 `2 * i + 1`，右孩子是 `2 * i + 2`。

三种操作分别对应：

1. 插入 `x`：先 `arr.push_back(x)` 把新元素放到数组末尾，再对它做一次**向上调整**（`heapInsert`），只要它比父节点小就与父节点交换并继续上浮；
2. 查询最小值：直接输出 `arr[0]`，不做任何修改；
3. 删除最小值：最小值在堆顶，先把它与当前堆的最后一个元素交换，再 `pop_back`（相当于把最小值移出堆），然后从堆顶做一次**向下调整**（`heappify`），让新的堆顶沉到合适的位置。

删除时“先交换再弹出”的顺序很重要：如果先把末尾元素弹掉，堆顶的最小值就丢失了；交换之后，被删掉的是末尾那个位置的旧堆顶。

### 复杂度分析

- 时间复杂度：单次向上调整或向下调整最多走过树的高度，完全二叉树的高度是 `O(log n)`，因此每次插入或删除是 `O(log n)`，查询是 `O(1)`；`n` 次操作合计 `O(n log n)`。
- 额外空间复杂度：`O(n)`，堆本身就是存放全部元素的数组，调整过程只用常数个变量（`l`、`r`、`best`、`i`），没有递归调用栈。

### 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Heap {
    void heapInsert(vector<int> &arr, int i) {
        // 新元素比父节点小就上浮；i = 0 时 (0 - 1) / 2 等于 0，循环自然结束。
        while (arr[i] < arr[(i - 1) / 2]) {
            //-1/2为0
            swap(arr[i], arr[(i - 1) / 2]);
            i = (i - 1) / 2;
        }
    }

    void heappify(vector<int> &arr, int i, int siz) {
        while ((i * 2 + 1) < siz) {
            // 选出两个孩子中较小的一个。
            int l = i * 2 + 1, r = l + 1;
            int best = l;
            if (r < siz && arr[l] > arr[r])
                best = r;
            // 比这个孩子大就交换，然后继续往下检查。
            if (arr[i] > arr[best])
                swap(arr[i], arr[best]);
            else
                break;
            i = best;
        }
    }
};

void solve() {
    int n;
    cin >> n;
    vector<int> arr;
    Heap heap;
    while (n--) {
        int op, x;
        cin >> op;
        if (op == 1) {
            // 插入：放到末尾再上浮。
            cin >> x;
            arr.push_back(x);
            heap.heapInsert(arr, arr.size() - 1);
        } else if (op == 2) {
            // 查询：堆顶就是最小值，不做修改。
            cout << arr[0] << endl;
        } else {
            // 删除：堆顶与末尾交换后弹出，再从堆顶下沉。
            swap(arr.back(), arr[0]);
            arr.pop_back();
            heap.heappify(arr, 0, arr.size());
        }
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);
    solve();
    return 0;
}
```

### 坑点

- 题目要维护的是最小值，所以必须用小根堆：向上调整比父节点**小**才交换，向下调整要选**较小**的孩子。写成大根堆会输出最大值。
- 删除操作中交换与弹出的顺序不能颠倒：先交换才能把最小值换到末尾，再 `pop_back` 才是删掉最小值。
- `heappify` 的第三个参数是当前堆的大小 `arr.size()`，不能传数组容量或旧的大小，否则调整会越过实际范围。
- 操作 2 只是输出，不删除元素；删除只在操作 3 发生，并且只删一个（题目保证有多个最小值时也只删 1 个）。
- 元素的取值范围是 `1 <= x < 2^31`，在 `int` 范围内，不需要开 `long long`。
