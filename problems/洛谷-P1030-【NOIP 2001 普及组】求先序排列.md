# 洛谷 P1030【NOIP 2001 普及组】求先序排列

## 题目来源

- 平台：洛谷
- 题号：P1030
- 原题链接：[P1030【NOIP 2001 普及组】求先序排列](https://www.luogu.com.cn/problem/P1030)

## 题面

给出一棵二叉树的中序与后序排列，求出它的先序排列。树节点使用互不相同的大写字母表示，节点个数不超过 `8`。

### 输入格式

输入两行，均为由大写字母组成的字符串，分别表示这棵二叉树的中序排列和后序排列。

### 输出格式

输出一行字符串，表示这棵二叉树的先序排列。

## 难度评估

D（入门）：题目只需要根据中序和后序序列递归确定当前根节点及左右子树，并按先序顺序输出。

## 解题思路

这道题不需要真的创建树节点，只要递归处理“当前子树的中序序列和后序序列”即可。

对于当前子树：

1. 后序遍历顺序是“左、右、根”，所以后序序列的最后一个字符一定是当前子树的根；
2. 在中序序列中找到根。根左边的部分是左子树的中序序列，根右边的部分是右子树的中序序列；
3. 设根在当前中序序列中的下标为 `k`。左子树有 `k` 个节点，因此后序序列去掉最后一个根后，前 `k` 个字符属于左子树，剩余字符属于右子树；
4. 先输出根，再递归左子树和右子树。输出顺序正好是“根、左、右”，也就是先序遍历。

当当前中序序列长度为 `0` 时，当前子树为空，递归结束。

### 样例过程

样例输入为：

```text
中序：BADC
后序：BDCA
```

后序序列的最后一个字符是 `A`，所以 `A` 是整棵树的根。`A` 在中序序列中将节点分成：

- 左子树：中序 `B`，后序 `B`；
- 右子树：中序 `DC`，后序 `DC`。

先输出根 `A`，再递归输出左子树和右子树，最终得到先序排列 `ABCD`。

### 字符串切分

代码使用 `substr` 传递左右子树的序列。需要特别注意：`substr` 的第一个参数是起点下标，第二个参数是从起点开始截取的字符数量，不是终点下标。

- 左子树：`in.substr(0, k)` 与 `pos.substr(0, k)`；
- 右子树：`in.substr(k + 1)` 与 `pos.substr(k)`。

### 代码对应关系

- `pos[n - 1]`：当前后序序列最后一个字符，即当前根；
- `in.find(pos[n - 1])`：在中序序列中定位根并确定左右子树规模；
- `preFind`：递归划分并保存每个节点的左右孩子；
- `preOrder`：按照“根、左、右”输出先序序列。

## 复杂度分析

设节点数为 `n`。每层递归都会对当前字符串执行 `find`、`erase`、`substr` 等操作；按照教练代码的字符串传递方式，最坏时间复杂度为 `O(n^2)`，额外空间复杂度为 `O(n^2)`（包括递归过程中产生的字符串副本）；节点数组本身只占用 `O(n)` 空间。题目给出的 `n <= 8`，该复杂度可以满足要求。

## 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using PII = array<int, 2>;
vector<PII> tree(20);

int preFind(string in, string pos) {
    int n = in.size();
    if (n == 0)
        return -1;

    // 后序最后一个字符是当前子树的根；用字符编号保存它。
    int num = pos[n - 1] - 'A';
    int k = in.find(pos[n - 1]);
    pos.erase(pos.end() - 1);

    // 中序根左侧和右侧分别对应左右子树；后序按左、右顺序切分。
    tree[num][0] = preFind(in.substr(0, k), pos.substr(0, k));
    tree[num][1] = preFind(in.substr(k + 1), pos.substr(k));
    return num;
}

void preOrder(int head) {
    // -1 表示空子树；当前子树没有节点时停止递归。
    if (head == -1)
        return;

    // 先输出根，再按先序顺序遍历左右子树。
    cout << char(head + 'A');
    preOrder(tree[head][0]);
    preOrder(tree[head][1]);
}

void solve() {
    string in, pos;
    cin >> in >> pos;
    preOrder(preFind(in, pos));
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);

    int T = 1;
    // cin>>T;
    while (T--)
        solve();
    return 0;
}
```

## 坑点

- 后序序列的最后一个字符才是当前子树的根，不是第一个字符。
- 中序序列中根左侧的长度决定后序序列中左子树部分的长度。
- `substr` 的第二个参数是长度，不是结束下标。
- 当前节点编号通过 `字符 - 'A'` 映射到数组下标，输出时再通过 `char(head + 'A')` 转回字符。
- 代码使用 `-1` 表示空子树，与 B3642 中使用的空节点编号 `0` 不同。
