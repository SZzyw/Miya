# 洛谷 P1177：【模板】排序

## 题目来源

- 平台：洛谷
- 题号：P1177
- 原题链接：[P1177 【模板】排序](https://www.luogu.com.cn/problem/P1177)

## 题面

给定若干整数，将它们按照从小到大的顺序排序并输出。

## 知识点

- 精确标签：排序
- 关联知识页：[[算法讲解004【入门】选择、冒泡、插入排序]]

## 难度评估

D（入门）：题目本身是排序模板题，主要考察排序算法的实现和输入输出。

## 解题思路

raw 笔记中使用冒泡排序：

- 每一轮从左到右比较相邻元素；
- 如果左边元素更大，就交换两个元素；
- 一轮结束后，当前未排序范围的最大值被放到最右侧；
- 缩小范围并重复。

## 教练代码

⚠️ 这份代码使用冒泡排序，时间复杂度为 O(n²)。对于 P1177 的数据规模会超时，这是正常现象；这里保留它作为冒泡排序过程的教学代码，不作为本题可通过的正式解法。

```cpp
#include <bits/stdc++.h>
using namespace std;

void func(vector<int> &v) {
    int n = v.size();

    for (int i = n - 1; i >= 0; --i) {
        for (int j = 0; j < i; ++j) {
            if (v[j] > v[j + 1]) {
                swap(v[j], v[j + 1]);
            }
        }
    }
}

void solve() {
    int n;
    cin >> n;
    vector<int> v(n);

    for (int i = 0; i < n; ++i) {
        cin >> v[i];
    }

    func(v);

    for (auto it : v) {
        cout << it << " ";
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);
    solve();
    return 0;
}
```

## 复杂度

时间复杂度为 O(n²)，额外空间复杂度为 O(1)。
