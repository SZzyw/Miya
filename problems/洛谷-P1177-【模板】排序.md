# 洛谷 P1177：【模板】排序

## 题目来源

- 平台：洛谷
- 题号：P1177
- 原题链接：[P1177 【模板】排序](https://www.luogu.com.cn/problem/P1177)

## 题面

给定若干整数，将它们按照从小到大的顺序排序并输出。

## 难度评估

D（入门）：题目本身是排序模板题，主要考察排序算法的实现和输入输出。

## 解法一：冒泡排序

### 解题思路

raw 笔记中使用冒泡排序：

- 每一轮从左到右比较相邻元素；
- 如果左边元素更大，就交换两个元素；
- 一轮结束后，当前未排序范围的最大值被放到最右侧；
- 缩小范围并重复。

### 复杂度分析

时间复杂度为 `O(n²)`，额外空间复杂度为 `O(1)`。

### 教练代码

⚠️ 这份代码使用冒泡排序，时间复杂度为 `O(n²)`。对于 P1177 的数据规模会超时，这是正常现象；这里保留它作为冒泡排序过程的教学代码，不作为本题可通过的正式解法。

```cpp
#include <bits/stdc++.h>
using namespace std;

void func(vector<int> &v) {
    int n = v.size();

    for (int i = n - 1; i >= 0; --i) {
        // 当前轮只处理 [0, i]，让这一段的最大值移动到 i。
        for (int j = 0; j < i; ++j) {
            // 相邻逆序时交换，较大的元素会逐步向右移动。
            if (v[j] > v[j + 1]) {
                swap(v[j], v[j + 1]);
            }
        }
    }
}

void solve() {
    int n;
    cin >> n;
    vector<int> v(n);

    for (int i = 0; i < n; ++i) {
        cin >> v[i];
    }

    func(v);

    for (auto it : v) {
        cout << it << " ";
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);
    solve();
    return 0;
}
```

### 坑点

- 冒泡排序适合用来理解相邻交换过程，但 `O(n²)` 的时间复杂度可能无法通过数据规模较大的排序题。
- raw 笔记提供了冒泡排序实现，没有提供提交结果；由于算法复杂度与题目规模不匹配，超时是预期结果。

## 解法二：归并排序

### 解题思路

归并排序先把数组递归划分成左右两部分，分别排好序，再利用两个有序区间完成合并：

1. 对左区间递归排序；
2. 对右区间递归排序；
3. 用两个指针分别指向左右有序区间的当前元素，每次取较小者放入辅助数组；
4. 某一侧耗尽后，把另一侧剩余的有序元素直接放入辅助数组；
5. 把辅助数组中的结果拷贝回原数组。

当区间只剩一个元素时，它天然有序，递归停止。具体的递归划分、`merge` 过程和步长递增的非递归思路见 [[算法讲解021【必备】归并排序]]。

### 复杂度分析

每层递归合计处理 `n` 个元素，共有 `O(log n)` 层，因此时间复杂度为 `O(n\log n)`。

空间复杂度分成三个层次：

1. **递归栈空间**：递归深度最多为 `O(log n)`，因此系统栈额外占用 `O(log n)`。
2. **辅助数组空间**：代码中的 `help` 长度与输入数组相同，因此辅助数组占用 `O(n)`。
3. **完整代码的额外空间**：同时考虑递归栈和 `help` 数组时，取两者的较大者，整体额外空间复杂度为 `O(n)`。

### 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct MergeSort {
    vector<int> &arr, help;

    MergeSort(vector<int> &arr) : arr(arr) {
        // 所有合并过程共用一份辅助数组，避免每次 merge 重复申请空间。
        help.resize(arr.size());
    }

    void merge(int l, int m, int r) {
        // [l, m] 与 [m + 1, r] 已经有序，按从小到大写入 help。
        for (int k = l, i = l, j = m + 1; k <= r; k++) {
            if (j == r + 1 || (i <= m && arr[i] <= arr[j])) {
                // 右半部分耗尽，或左侧当前值不大于右侧当前值时，取左侧元素。
                help[k] = arr[i];
                i++;
            } else {
                // 左侧当前值更大时，取右侧元素。
                help[k] = arr[j];
                j++;
            }
        }

        // 将当前区间的有序结果覆盖回原数组。
        for (int i = l; i <= r; i++) {
            arr[i] = help[i];
        }
    }

    void mergeSort(int l, int r) {
        // 单元素区间天然有序，递归在这里停止。
        if (l == r)
            return;

        // 先分别处理左右区间，再合并两个有序结果。
        int m = l + (r - l) / 2;
        mergeSort(l, m);
        mergeSort(m + 1, r);
        merge(l, m, r);
    }
};

vector<int> nums;

void solve() {
    int n;
    cin >> n;
    nums.resize(n);
    for (int i = 0; i < n; i++)
        cin >> nums[i];

    MergeSort sor(nums);
    sor.mergeSort(0, nums.size() - 1);

    for (auto it: nums) {
        cout << it << " ";
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);
    int T = 1;
    // cin>>T;
    while (T--)
        solve();
    return 0;
}
```

### 坑点

- 这份 `mergeSort` 的终止条件是 `l == r`，因此调用区间需要非空。P1177 的输入范围满足 `n >= 1`，所以从 `mergeSort(0, nums.size() - 1)` 调用时不会得到空区间。
- `merge` 只应在左右两部分已经分别有序时调用；否则“每次取两侧较小值”的合并依据不成立。
- 左右当前元素相等时，代码使用 `arr[i] <= arr[j]`，会优先取左侧元素。
