# 洛谷 P1177：【模板】排序

## 题目来源

- 平台：洛谷
- 题号：P1177
- 原题链接：[P1177 【模板】排序](https://www.luogu.com.cn/problem/P1177)

## 题面

给定若干整数，将它们按照从小到大的顺序排序并输出。

## 难度评估

D（入门）：题目本身是排序模板题，主要考察排序算法的实现和输入输出。

## 解法一：冒泡排序

### 解题思路

raw 笔记中使用冒泡排序：

- 每一轮从左到右比较相邻元素；
- 如果左边元素更大，就交换两个元素；
- 一轮结束后，当前未排序范围的最大值被放到最右侧；
- 缩小范围并重复。

### 复杂度分析

时间复杂度为 `O(n²)`，额外空间复杂度为 `O(1)`。

### 教练代码

注意：这份代码使用冒泡排序，时间复杂度为 `O(n²)`。对于 P1177 的数据规模会超时，这是正常现象；这里保留它作为冒泡排序过程的教学代码，不作为本题可通过的正式解法。

```cpp
#include <bits/stdc++.h>
using namespace std;

void func(vector<int> &v) {
    int n = v.size();

    for (int i = n - 1; i >= 0; --i) {
        // 当前轮只处理 [0, i]，让这一段的最大值移动到 i。
        for (int j = 0; j < i; ++j) {
            // 相邻逆序时交换，较大的元素会逐步向右移动。
            if (v[j] > v[j + 1]) {
                swap(v[j], v[j + 1]);
            }
        }
    }
}

void solve() {
    int n;
    cin >> n;
    vector<int> v(n);

    for (int i = 0; i < n; ++i) {
        cin >> v[i];
    }

    func(v);

    for (auto it : v) {
        cout << it << " ";
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);
    solve();
    return 0;
}
```

### 坑点

- 冒泡排序适合用来理解相邻交换过程，但 `O(n²)` 的时间复杂度可能无法通过数据规模较大的排序题。
- raw 笔记提供了冒泡排序实现，没有提供提交结果；由于算法复杂度与题目规模不匹配，超时是预期结果。

## 解法二：归并排序

### 解题思路

归并排序先把数组递归划分成左右两部分，分别排好序，再利用两个有序区间完成合并：

1. 对左区间递归排序；
2. 对右区间递归排序；
3. 用两个指针分别指向左右有序区间的当前元素，每次取较小者放入辅助数组；
4. 某一侧耗尽后，把另一侧剩余的有序元素直接放入辅助数组；
5. 把辅助数组中的结果拷贝回原数组。

当区间只剩一个元素时，它天然有序，递归停止。具体的递归划分、`merge` 过程和步长递增的非递归思路见 [[算法讲解021【必备】归并排序]]。

### 复杂度分析

每层递归合计处理 `n` 个元素，共有 `O(log n)` 层，因此时间复杂度为 `O(nlog n)`。

空间复杂度分成三个层次：

1. **递归栈空间**：递归深度最多为 `O(log n)`，因此系统栈额外占用 `O(log n)`。
2. **辅助数组空间**：代码中的 `help` 长度与输入数组相同，因此辅助数组占用 `O(n)`。
3. **完整代码的额外空间**：同时考虑递归栈和 `help` 数组时，取两者的较大者，整体额外空间复杂度为 `O(n)`。

### 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct MergeSort {
    vector<int> &arr, help;

    MergeSort(vector<int> &arr) : arr(arr) {
        // 所有合并过程共用一份辅助数组，避免每次 merge 重复申请空间。
        help.resize(arr.size());
    }

    void merge(int l, int m, int r) {
        // [l, m] 与 [m + 1, r] 已经有序，按从小到大写入 help。
        for (int k = l, i = l, j = m + 1; k <= r; k++) {
            if (j == r + 1 || (i <= m && arr[i] <= arr[j])) {
                // 右半部分耗尽，或左侧当前值不大于右侧当前值时，取左侧元素。
                help[k] = arr[i];
                i++;
            } else {
                // 左侧当前值更大时，取右侧元素。
                help[k] = arr[j];
                j++;
            }
        }

        // 将当前区间的有序结果覆盖回原数组。
        for (int i = l; i <= r; i++) {
            arr[i] = help[i];
        }
    }

    void mergeSort(int l, int r) {
        // 单元素区间天然有序，递归在这里停止。
        if (l == r)
            return;

        // 先分别处理左右区间，再合并两个有序结果。
        int m = l + (r - l) / 2;
        mergeSort(l, m);
        mergeSort(m + 1, r);
        merge(l, m, r);
    }
};

vector<int> nums;

void solve() {
    int n;
    cin >> n;
    nums.resize(n);
    for (int i = 0; i < n; i++)
        cin >> nums[i];

    MergeSort sor(nums);
    sor.mergeSort(0, nums.size() - 1);

    for (auto it: nums) {
        cout << it << " ";
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);
    int T = 1;
    // cin>>T;
    while (T--)
        solve();
    return 0;
}
```

### 坑点

- 这份 `mergeSort` 的终止条件是 `l == r`，因此调用区间需要非空。P1177 的输入范围满足 `n >= 1`，所以从 `mergeSort(0, nums.size() - 1)` 调用时不会得到空区间。
- `merge` 只应在左右两部分已经分别有序时调用；否则“每次取两侧较小值”的合并依据不成立。
- 左右当前元素相等时，代码使用 `arr[i] <= arr[j]`，会优先取左侧元素。

## 解法三：随机快速排序

### 解题思路

raw 笔记中的模板代码使用随机快速排序，并采用三路划分：

1. 在当前区间 `[l, r]` 中随机选取一个元素作为划分值 `x`。
2. 将区间整理成三段：小于 `x` 的元素在左边，等于 `x` 的元素在中间，大于 `x` 的元素在右边。
3. 中间的等值区间已经不需要继续排序，只递归处理左段和右段。

`partition` 中的 `first` 是左侧“小于 `x`”区域的右边界后一格，`last` 是右侧“大于 `x`”区域的左边界前一格。扫描指针 `i` 从左向右处理尚未确定的元素：

- `arr[i] < x`：交换到 `first` 位置，然后扩大左段；
- `arr[i] == x`：它已经属于中段，扫描指针继续向右；
- `arr[i] > x`：交换到 `last` 位置，并缩小右段。

大于 `x` 的元素交换后，换回 `i` 位置的新元素还没有被检查，因此代码中的 `i--` 很关键。`for` 循环随后会执行 `i++`，抵消这次回退，下一轮仍会检查同一个位置。

划分完成后，`[first, last]` 中的所有元素都等于 `x`。这些元素一次性被确定，不会像单点划分那样因为重复值继续进入递归；因此递归调用的区间是 `[l, first - 1]` 和 `[last + 1, r]`。

### 复杂度分析

随机快速排序的期望时间复杂度为 `O(n\\log n)`，因为随机选择划分值后，递归树在期望意义下保持较好的平衡，每层合计处理的元素数量为 `O(n)`，递归层数期望为 `O(\\log n)`。

三路划分对重复元素更友好：如果当前区间中的元素全部相等，一次线性扫描即可把它们放入中段，当前层的时间复杂度为 `O(n)`，左右两边都不再递归。

最坏时间复杂度仍然是 `O(n^2)`。如果连续选到靠近区间边界的划分值，递归区间每次只缩小很少，递归树会退化。额外空间主要是递归栈：期望或理想情况下为 `O(\\log n)`，最坏情况下为 `O(n)`；三路划分本身只使用常数个变量，额外空间为 `O(1)`。

### 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long

struct QuickSort {
    vector<int> &arr;

    QuickSort(vector<int> &arr) : arr(arr) {
    }

    array<int, 2> partition(int l, int r, int x) {
        // first 左侧维护小于 x 的区域，last 右侧维护大于 x 的区域。
        int first = l, last = r;
        for (int i = l; i <= last; i++) {
            if (arr[i] < x)
                // 当前值属于左段，交换到 first 位置并扩大左段。
                swap(arr[i], arr[first++]);
            else if (arr[i] > x)
                // 右侧换回来的元素还未检查，i-- 用来抵消 for 的自增。
                swap(arr[i--], arr[last--]);
        }
        return {first, last};
    }

    void quickSort(int l, int r) {
        // 区间至多一个元素时已经有序，不需要继续递归。
        if (l >= r)
            return;

        // 随机选择当前区间中的一个元素作为划分值。
        int x = arr[rand() % (r - l + 1) + l];
        array<int, 2> mid = partition(l, r, x);

        // 等于 x 的中段已经处理完，只递归左右两段。
        quickSort(l, mid[0] - 1);
        quickSort(mid[1] + 1, r);
    }
};

vector<int> nums;

void solve() {
    int n;
    cin >> n;
    nums.resize(n);
    for (int i = 0; i < n; i++)
        cin >> nums[i];
    QuickSort quick_sort(nums);
    quick_sort.quickSort(0, nums.size() - 1);
    for (auto it: nums) {
        cout << it << " ";
    }
}

signed main() {
    srand(time(0));
    ios::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);
    int T = 1;
    // cin>>T;
    while (T--)
        solve();
    return 0;
}
```

### 坑点

- 遇到 `arr[i] > x` 时必须执行 `i--`。交换回来的元素此前没有经过分类，跳过它会破坏三段区域的不变量。
- `x` 是从当前区间中随机取出的元素，因此当前区间一定存在等于 `x` 的元素；模板不能把 `partition` 的划分值替换成区间外不存在的值。
- 等于 `x` 的中段是 `[mid[0], mid[1]]`，递归边界必须跳过它，使用 `[l, mid[0] - 1]` 和 `[mid[1] + 1, r]`。
- 随机化降低连续极不平衡划分的概率，但不能把最坏复杂度从 `O(n^2)` 消除；期望复杂度和最坏复杂度不能混为一谈。
- 模板在 `main` 中调用 `srand(time(0))` 后再进行随机选择。`quickSort` 的递归实现按非空区间调用，当前模板的 `nums.size() - 1` 也依赖输入规模至少为 1。

## 解法四：手写堆排序

### 解题思路

raw 笔记中的模板代码使用手写堆排序（大根堆），不使用 STL 的 `priority_queue`。整个过程分成两步：

1. **建堆**：从左到右把每个元素用 `heapInsert` 插入堆。新元素一开始放在数组末尾，然后不断和父节点比较，比自己父节点大就交换并继续向上，直到不大于父节点或到达根节点。这一步结束时，整个数组满足大根堆性质。
2. **排序**：重复 `n - 1` 轮，每轮把堆顶 `arr[0]`（当前堆里的最大值）与当前堆的最后一个位置 `arr[i]` 交换，堆的大小变成 `i`，再对新的堆顶调用 `heappify` 向下调整，恢复大根堆性质。每轮都把当前最大值放到堆区间之外的最右侧，因此结束时数组从小到大有序。

堆用数组表示：下标 `i` 的左孩子是 `2 * i + 1`，右孩子是 `2 * i + 2`，父节点是 `(i - 1) / 2`。`heappify` 每次先选出两个孩子中较大的一个，如果当前节点比它小就交换并继续向下检查，否则说明当前位置已经满足大根堆性质，可以停止。

两种建堆方向的差别、`[6,6,5,4]` 的完整建堆与排序过程见 [[算法讲解025【必备】堆排序]]。

### 复杂度分析

- 时间复杂度：建堆阶段每个元素上浮的代价是 `O(log n)`，共 `n` 个元素，因此建堆为 `O(n log n)`；排序阶段共 `n - 1` 轮，每轮一次交换加上一次 `O(log n)` 的向下调整，合计 `O(n log n)`。两部分相加，整体时间复杂度为 `O(n log n)`。（如果把建堆换成自底到顶的写法，建堆本身可以做到 `O(n)`，但排序阶段仍是 `O(n log n)`，整体量级不变。）
- 额外空间复杂度：`O(1)`。所有调整都在原数组上交换完成，只使用 `n`、`l`、`r`、`best`、`i` 等常数个变量；`heapInsert` 和 `heappify` 都用循环实现，没有额外的递归调用栈。

### 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct HeapSort {
    // 把下标 i 的新元素向上调整到合适位置，维持大根堆性质。
    void heapInsert(vector<int> &arr, int i) {
        while (arr[i] > arr[(i - 1) / 2]) {
            //-1/2为0
            swap(arr[i], arr[(i - 1) / 2]);
            i = (i - 1) / 2;
        }
    }

    // 让下标 i 的节点在大小为 siz 的堆内向下调整。
    void heappify(vector<int> &arr, int i, int siz) {
        while ((i * 2 + 1) < siz) {
            // 先选出两个孩子中较大的一个。
            int l = i * 2 + 1, r = l + 1;
            int best = l;
            if (r < siz && arr[l] < arr[r])
                best = r;
            // 比这个孩子小就交换并继续下沉，否则已经满足大根堆性质。
            if (arr[i] < arr[best])
                swap(arr[i], arr[best]);
            else
                break;
            i = best;
        }
    }

    void heapSort(vector<int> &arr) {
        int n = arr.size();
        // 建堆：从左到右插入每个元素，新元素一路上浮。
        for (int i = 0; i < n; i++)
            heapInsert(arr, i);
        // 排序：堆顶换到当前堆的末尾，堆缩小后重新调整堆顶。
        for (int i = n - 1; i > 0; i--) {
            swap(arr[0], arr[i]);
            heappify(arr, 0, i);
        }
    }
};

void solve() {
    int n;
    cin >> n;
    vector<int> arr(n);
    for (int i = 0; i < n; i++)
        cin >> arr[i];
    HeapSort heapsort;
    heapsort.heapSort(arr);
    for (int i = 0; i < n; i++)
        cout << arr[i] << " ";
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);
    solve();
    return 0;
}
```

### 坑点

- `heapInsert` 中的 `(i - 1) / 2` 依赖 C++ 整数除法向零取整：`i = 0` 时 `(0 - 1) / 2` 等于 `0`，判断变成 `arr[0] > arr[0]`，循环自然结束。如果换成对负数向下取整的写法，就会访问下标 `-1`。
- `heappify` 的第三个参数是当前堆的大小，不是数组长度。排序阶段堆在不断缩小，必须传入 `i`；传 `n` 会把已经放到末尾的有序元素重新拉回堆里。
- 先交换堆顶再下调的顺序不能颠倒。交换之后堆顶是被换下来的元素，需要从堆顶重新向下调整；如果先调整再交换，调整时堆本来就是合法的，等于什么都没做，交换之后堆顶反而被破坏了。
- 这里用大根堆配合“堆顶换到末尾”，得到的是升序结果；如果要降序，需要改成小根堆。
- `heappify` 中的 `else break` 不能省略。走到这个分支说明当前节点已经不小于较大的孩子，而下面的子树本来就是堆，所以可以停止下沉。
