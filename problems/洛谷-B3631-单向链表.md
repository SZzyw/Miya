# 洛谷 B3631 单向链表

## 题目来源

原题链接：[洛谷 B3631 单向链表](https://www.luogu.com.cn/problem/B3631)

## 题面

初始只有元素 0，支持在元素 x 后插入 y、查询 x 后面的元素、删除 x 后面的元素；最后一个元素的后继按题意输出 0。

## 难度评估

D（入门/基础）：核心是维护链表节点之间的连接关系。

## 解题思路

使用节点的 `next` 或 `pre` 记录连接。插入时先保存原连接，再同时修改受影响的相邻节点；删除时让删除节点两侧直接相连。

## 复杂度分析

单次链表操作只修改常数个连接，时间复杂度为 $O(1)$；遍历链表为 $O(n)$，额外空间取决于保存节点的方式。

## 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 1e6 + 10;

struct Node {
    int val;
    int next;

    Node(int val = -1, int next = -1) : val(val), next(next) {
    }
};

vector<Node> arr;
vector<int> fin(N);

void init() {
    // 0 号节点作为初始节点；单链表用 -1 表示暂时没有后继。
    arr.push_back(Node(0, -1));
}

void insert(int x, int y) {
    // fin 把元素编号转换为 arr 中的节点下标。
    x = fin[x];

    // 新节点先接上 x 原来的后继，再让 x 指向新节点，避免丢失后半段链表。
    fin[y] = arr.size();
    arr.push_back(Node(y, arr[x].next));
    arr[x].next = fin[y];
}

int coutNode(int x) {
    // x 没有后继时按题意返回 0；否则读取后继节点的元素值。
    if (arr[fin[x]].next == -1)
        return 0;
    return arr[arr[fin[x]].next].val;
}

void erase(int x) {
    // 删除的是 x 后面的节点，让 x 直接连接被删除节点的后继。
    x = fin[x];
    arr[x].next = arr[arr[x].next].next;
}

void solve() {
    int q;
    cin >> q;
    init();

    // 题目初始只有元素 0，先把元素 1 插到它后面。
    insert(0, 1);
    while (q--) {
        int a, x, y;
        cin >> a;
        if (a == 1) {
            // 操作 1 在 x 后插入 y；函数内部完成编号到节点下标的转换。
            cin >> x >> y;
            insert(x, y);
        } else if (a == 2) {
            // 操作 2 查询 x 的后继，并按题意输出其元素值。
            cin >> x;
            cout << coutNode(x) << endl;
        } else {
            // 其他操作删除 x 的后继，而不是删除 x 本身。
            cin >> x;
            erase(x);
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);
    solve();
    return 0;
}

```

## 坑点

- `next` 保存节点下标，`fin` 用于元素编号到节点下标的转换。
- 删除操作删除的是 `x` 后面的节点。
