# 牛客 计算数组的小和

## 题目来源

- 平台：牛客
- 题名：计算数组的小和
- 原题链接：[计算数组的小和_牛客题霸](https://www.nowcoder.com/practice/edfe05a1d45c4ea89101d936cac32469)

## 题面

数组小和的定义是：对于数组中的每个元素，求它左侧所有小于等于当前元素的数之和，再把每个元素对应的这份和累加起来。

例如数组 `[1, 3, 5, 2, 4, 6]`：

- `1` 左侧没有元素，贡献为 `0`；
- `3` 左侧小于等于 `3` 的元素为 `1`，贡献为 `1`；
- `5` 左侧小于等于 `5` 的元素为 `1、3`，贡献为 `4`；
- `2` 左侧小于等于 `2` 的元素为 `1`，贡献为 `1`；
- `4` 左侧小于等于 `4` 的元素为 `1、3、2`，贡献为 `6`；
- `6` 左侧小于等于 `6` 的元素为 `1、3、5、2、4`，贡献为 `15`。

因此数组小和为 `0 + 1 + 4 + 1 + 6 + 15 = 27`。

### 输入格式

- 第一行输入一个整数 `N`，表示数组长度；
- 接下来一行输入 `N` 个整数，表示数组元素。

### 输出格式

输出一个整数，表示数组的小和。

题目链接的页面检索结果没有显示完整数据范围，本页不补写未确认的范围。

## 难度评估

C（基础）：题目需要在归并排序的 `merge` 阶段统计跨越左右区间的贡献，不能只实现普通排序。

## 解法：归并分治

### 解题思路

直接按照定义，对每个位置向左枚举并累加满足条件的元素，需要重复比较大量下标对，时间复杂度为 `O(n^2)`。归并分治把这些下标对按分治区间拆成三类：

1. 两个下标都在左半区间内；
2. 两个下标都在右半区间内；
3. 左侧下标在左半区间、右侧下标在右半区间。

前两类分别由递归调用统计，第三类在合并左右两个有序区间时统计。这样每一对满足条件的下标只会在它们第一次被分到左右两侧的那次 `merge` 中统计一次。

设当前区间为 `[l, r]`，中点为 `m`。递归函数返回：

```text
左区间小和 + 右区间小和 + 跨区间小和
```

`merge` 时，左区间 `[l, m]` 和右区间 `[m + 1, r]` 已经分别有序。代码使用两个指针 `i`、`j` 合并，并用 `sum` 保存已经取出的左侧元素之和：

- 如果 `arr[i] <= arr[j]`，先把 `arr[i]` 放入辅助数组，并把它加入 `sum`；
- 由于右区间有序，之后每取出一个当前值不小于这些左侧元素的右侧元素，就可以把 `sum` 一次性加入答案；
- 如果当前取出右侧元素 `arr[j]`，执行 `ans += sum`，再继续合并；
- 合并完成后把 `help[l..r]` 写回 `arr[l..r]`，为更高层的 `merge` 保持有序前提。

这里使用 `<=`，所以左右当前元素相等时会先取左侧元素；等号也属于题目“小于等于”的条件，能够被正确计入。

从下标对的角度看，任意一对 `i < j` 要么完全位于左区间，要么完全位于右区间，要么跨越左右分界线，三种情况互不重叠且覆盖所有可能，因此递归统计不会重复或遗漏。

### 复杂度分析

每层递归中的所有 `merge` 合计线性处理当前数组元素。如果 `merge` 对长度为 `k` 的区间使用 `O(k)` 时间，那么递归共有 `O(log n)` 层，总时间复杂度为 `O(n log n)`。

- 时间复杂度：`O(n log n)`；
- `help` 辅助数组空间：`O(n)`；
- 递归栈空间：`O(log n)`；
- 完整代码额外空间：`O(n)`。

### 教练代码

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long

struct SmallSum {
    vector<int> &arr, help;

    SmallSum(vector<int> &arr) : arr(arr) {
        // 辅助数组只申请一次，供所有 merge 过程重复使用。
        help.resize(arr.size());
    }

    int merge(int l, int m, int r) {
        int ans = 0, sum = 0;

        // 左右区间都已分别有序；k 写入合并结果，i、j 指向两侧当前元素。
        for (int k = l, i = l, j = m + 1; k <= r; k++) {
            if (j == r + 1 || (i <= m && arr[i] <= arr[j])) {
                // 当前取左值；它会作为后续右值左侧的有效贡献。
                sum += arr[i];
                help[k] = arr[i];
                i++;
            } else {
                // 当前取右值，左侧已取出的元素之和一次性计入答案。
                ans += sum;
                help[k] = arr[j];
                j++;
            }
        }

        // 合并结果写回原数组，保证更高层 merge 继续接收有序区间。
        for (int i = l; i <= r; i++) {
            arr[i] = help[i];
        }
        return ans;
    }

    int smallSum(int l, int r) {
        // 单元素区间没有其他元素可以为它贡献小和。
        if (l == r)
            return 0;

        // 先统计左右内部贡献，再统计跨越左右分界线的贡献。
        int m = l + (r - l) / 2;
        return smallSum(l, m) + smallSum(m + 1, r) + merge(l, m, r);
    }
};

vector<int> nums;

void solve() {
    int n;
    cin >> n;
    nums.resize(n);
    for (int i = 0; i < n; i++)
        cin >> nums[i];

    SmallSum small_sum(nums);
    cout << small_sum.smallSum(0, nums.size() - 1);
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);
    int T = 1;
    // cin>>T;
    while (T--)
        solve();
    return 0;
}
```

### 坑点

- 题目条件是“小于等于”，因此 `merge` 中必须使用 `arr[i] <= arr[j]`；相等时不能漏计。
- `sum` 保存的是左侧元素的**数值之和**，不是元素个数；小和与逆序对的统计变量含义不同。
- `merge` 只能在左右区间已经分别有序时使用，否则无法一次性确定一批跨区间贡献。
- 这份教练代码的递归终止条件是 `l == r`，初始调用要求区间非空。如果题目允许 `N = 0`，`smallSum(0, nums.size() - 1)` 会传入空区间，需由教练确认题目保证；当前代码逻辑未修改。
- `#define int long long` 使答案累加使用 64 位整数，避免小和过大时溢出。
