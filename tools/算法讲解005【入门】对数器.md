# 对数器

对数器主要用于找出代码中的错误数据。它的基本方法是：准备一个容易保证正确的暴力解，再准备待测试的高效解，随机生成很多输入，让两份程序处理完全相同的数据，然后比较输出。

## 使用流程

1. 实现待测试的方法 a，也就是复杂度更好的解法。
2. 实现方法 b，也就是复杂度较差但容易保证正确的暴力解。
3. 实现随机样本生成器，随机化样本长度和值。
4. 把同一个样本交给方法 a 和方法 b。
5. 如果输出不一致，打印导致错误的样本，人工定位问题。
6. 当大量随机样本都通过后，再结合边界样例继续检查方法 a。

对数器不能从数学上证明代码一定正确，但可以大幅提高发现错误的概率；暴力解本身必须先确认正确。

## Windows 对拍代码

下面的代码使用 Windows 命令行中的 g++、可执行文件重定向和 fc 文件比较命令。

```cpp
int main()
{
    // 编译数据生成器、待测试程序和标准答案程序
    system("g++ -std=c++11 shuju.cpp -o shuju.exe");
    system("g++ -std=c++11 my.cpp -o my.exe");
    system("g++ -std=c++11 ans.cpp -o ans.exe");

    // 持续生成数据并比较两份程序的输出
    while (1)
    {
        system("shuju.exe > shuju.txt");
        system("ans.exe < shuju.txt > ans.txt");
        system("my.exe < shuju.txt > my.txt");

        if (system("fc ans.txt my.txt"))
        {
            cout << "Wrong Answer" << endl;
            break;
        }
        else
        {
            cout << "AC" << endl;
        }
    }

    return 0;
}
```

这段代码依赖 Windows 的 fc 命令；在 Linux 或 WSL 中需要改用对应的文件比较命令，不能直接照搬。

## 随机数生成示例

```cpp
void solve()
{
    mt19937 engine(time(0));
    cout << engine() << endl;
}
```

这段代码只演示如何创建随机引擎并输出一个随机数，还不是完整的测试数据生成器。实际使用时还需要根据题目格式生成随机长度、随机元素以及合法输入。

## 常见坑

- 暴力解不正确时，对拍结果没有意义。
- 随机样本必须覆盖最小规模、最大规模、重复值、极值和特殊结构。
- 发现不一致时要保留出错样本，便于复现和定位。
- Windows 的 fc、Linux 的 diff 等命令不能不加修改地跨环境使用。
- time(0) 作为种子在很短时间内重复启动程序时可能产生相同种子；需要复现时应记录种子。
