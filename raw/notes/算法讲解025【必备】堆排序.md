#### 堆排序
先将数组变为一个堆，接着每次将arr\[0\]和arr\[siz\]交换（堆的大小），堆大小-1
举例：\[6,6,5,4\]

#### 自顶到底建堆
从顶部开始把一个数组变为堆

```c++
    void heapSort(vector<int> &arr) {
        int n=arr.size();
        for (int i=0;i<n;i++)
            heapInsert(arr,i);
        for (int i=n-1;i>0;i--) {
            swap(arr[0], arr[i]);
            heappify(arr, 0, i);
        }
    }
```

##### 时间复杂度n
每次向上调整的时间复杂度都是$log n$,也就是树的高度。
因此n个数时间复杂度为$log1+log2+log3+....+logn = n*logn$
交换时，每次向下调整的时间复杂度都是$log n$，是剩余树的大小。
因此n个数时间复杂度为$log1+log2+log3+....+logn = n*logn$
总时间复杂度$n*logn$

#### 自底到顶建堆
从底部开始把一个数组变为堆

```c++
    void heapSort(vector<int> &arr) {
        int n=arr.size();
        for (int i=n-1;i>=0;i--) 
            heappify(arr,i,n);
        for (int i=n-1;i>0;i--) {
            swap(arr[0], arr[i]);
            heappify(arr, 0, i);
        }
    }
```

##### 时间复杂度
最底下的叶子节点其子树的高度为1，因此有$n/2$的节点复杂度为1.
再往上的叶子节点其子树的高度为2，因此有$n/4$的节点复杂度为2
再往上的叶子节点其子树的高度为3，因此有$n/8$的节点复杂度为3
直到最后，因此时间复杂度是O(n)。
交换时，每次向下调整的时间复杂度都是$log n$，是剩余树的大小。
因此n个数时间复杂度为$log1+log2+log3+....+logn = n*logn$
总时间复杂度$n*logn$

#### 为什么不同的做法时间复杂度不一样
自顶到底建堆，越往下时间复杂度越高，同时每一层的点数量变多。
自底到顶建堆，越往上时间复杂度越搞，同时每一层的点数量变少。

#### 模板题
[P1177 【模板】排序 - 洛谷](https://www.luogu.com.cn/problem/P1177)

```c++
#include <bits/stdc++.h>
using namespace std;

struct HeapSort {
    void heapInsert(vector<int> &arr, int i) {
        while (arr[i] > arr[(i - 1) / 2]) {
            //-1/2为0
            swap(arr[i], arr[(i - 1) / 2]);
            i = (i - 1) / 2;
        }
    }

    void heappify(vector<int> &arr, int i, int siz) {
        while ((i * 2 + 1) < siz) {
            int l = i * 2 + 1, r = l + 1;
            int best = l;
            if (r < siz && arr[l] < arr[r])
                best = r;
            if (arr[i] < arr[best])
                swap(arr[i], arr[best]);
            else
                break;
            i = best;
        }
    }

    void heapSort(vector<int> &arr) {
        int n = arr.size();
        for (int i = 0; i < n; i++)
            heapInsert(arr, i);
        for (int i = n - 1; i > 0; i--) {
            swap(arr[0], arr[i]);
            heappify(arr, 0, i);
        }
    }
};

void solve() {
    int n;
    cin >> n;
    vector<int> arr(n);
    for (int i = 0; i < n; i++)
        cin >> arr[i];
    HeapSort heapsort;
    heapsort.heapSort(arr);
    for (int i = 0; i < n; i++)
        cout << arr[i] << " ";
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);
    solve();
    return 0;
}
```
