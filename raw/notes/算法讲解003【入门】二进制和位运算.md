其他：位运算
#### 二进制的概念
什么是十进制?
从右往左，每个都是10的幂次的倍数
$103=10^0*3+10^1*0+10^2*1$
二进制同理
从右往左，每个都是2的幂次的倍数
$101=2^0*1+2^1*0+2^2*1$

在计算机当中，所有的东西都是二进制。计算机只能做二进制的计算，也只能做位运算。

在数的前面加上0b表明这个数是二进制数

#### 位的概念
这里的位就表明有多少位数。跟10进制一样，1848是4位数。二进制下0b1011是4位数。

#### 正数十进制转二进制
$5=0b101=2^0*1+2^1*0+2^2*1$，除了第0位，每个数都能被2整除，因此我们每次将这个数/2，余下来的数就是最小的未知的二进制的值,一直除到这个数为0为止

$5/2=2 ...... 1$           $0b1$
$2/2=1 ...... 0$           $0b01$
$1/2=0 ...... 1$           $0b101$
$0b101\xrightarrow{\text{符号位0}}0b0101$
处理5位
```c++
void func(int value) {
    stack<int> s;      // 声明一个整型栈，用于存储余数

    // 第一阶段：反复除以2，直到商为0，将每次的余数压入栈
    while (value != 0) {
        s.push(value % 2);   // 取当前 value 除以2的余数（0或1），压入栈
        value /= 2;          // 更新 value 为除以2的商（整数除法）
    }

	while(s.size()<5)
		s.push(0);

    // 第二阶段：从栈顶到栈底依次弹出并输出，即得到正确的二进制位（高位在前）
    while (s.size() != 0) {
        cout << s.top();     // 输出栈顶元素（当前最高位）
        s.pop();             // 移除已输出的栈顶元素
    }
}
```

#### 无符号数据范围计算
int内存占4个字节，共消耗32位，long long内存占8个字节，共消耗64位.
那如何通过位数来计算非负整数范围呢。  比如4位10进制，那么最小就是0，最大就是9999，因此数据范围就是$0\sim9999$，也就是$0\sim10^4-1$

因此。
在无符号的int情况下(unsigned int)：$0\sim2^{32}-1$
在无符号的long long情况下(unsigned long long)：$0\sim2^{64}-1$

#### 负数十进制转二进制
那负数怎么办？在10进制计算中，会添加一个负号来表明这是这是负数。但二进制中没有负号这个概念，因此把二进制位数的最高位来表明这个数是正数还是负数，也就是符号位。比如一个4位的二进制，第3位就是符号位。

先把这个数取绝对值再减1，求出二进制数，将这个二进制数每一位都取反，此时就是该数的二进制了
$-5\xrightarrow{\text{取绝对值}}5\xrightarrow{\text{-1}}4$
$4/2=2 ...... 0$           $0b0$
$2/2=1 ...... 0$           $0b01$
$1/2=0 ...... 1$           $0b100$
$0b0100 \xrightarrow{\text{取反}} 0b1011$
-5=0b1011
处理5位
```c++
void func(int value) {
    // 对负数取反，并-1
    value = -value - 1;      

    stack<int> s;            // 用于逆序存储二进制位

    // 除二取余（此时 value ≥ 0，% 和 / 行为正确）
    while (value != 0) {
        s.push(value % 2);   // 取当前 value 除以2的余数（0或1），压入栈
        value /= 2;          // 更新 value 为除以2的商（整数除法）
    }

	while(s.size()<5)
		s.push(0);

    // 依次弹出栈顶（从最高位到最低位），并逐位取反后输出
    while (s.size() != 0) {
        if (s.top() == 1)
            cout << 0;        // 遇 1 输出 0
        else
            cout << 1;        // 遇 0 输出 1
        s.pop();
    }
}

```

#### 有符号为最小数特殊性
因为这个减1，导致4位的二进制数可以表示-4。虽然正整数的4是0b1000把符号位占用了，但减1后就是0b0111符号位就空出来了，再取反就是0b1000。
注意：4是0b1000（无符号位），-4是0b1000（有符号位）。因此，在有符号位的情况下，切位数固定，最小值的绝对值就是其本身。

#### 带符号数据范围计算
假设4位，那最小的二进制数是多少？0b1000对吧，也就是-8，那最大的二进制数是多少？0b0111，也就是7.因此数据范围是$-8\sim7$ .也就是$-2^3\sim2^3-1$ 

因此。
在有符号的int情况下(unsigned int)：$-2^{31}\sim2^{31}-1$
在有符号的long long情况下(unsigned long long)：$-2^{63}\sim2^{63}-1$

#### 16进制
在数的前面加上0x表明这个数是二进制数
16禁制下，<10的数字仍然用数字，>=10用字母，a=10,b=11,c=12,d=13,e=14,f=15
10进制转16进制与10进制转2进制的原理是一样的。
2进制与16进制可以快速转换，2进制的4位=16进制的1位

#### 常见的位运算
~：取反，`~ 0b10010=0b01101` 
<<:将二进制数进行左移，补充0：`0b10010 << 1 = 0b10100`
\>\>:将二进制数进行右移，补充符号位: `0b10010 >> 1 = 0b11001
\>\>\>:将二进制数进行右移，补充0 `0b10010 >>> 1 = 0b01001
&：相当于and，`0b10010 & 0b01011 = 0b00010`
^:相同取0，不同取1，`0b10010 ^ 0b01011 = 0b11001`
|：相当于or，`0b10010 | 0b01011 = 0b11011`

非负数 << x ,相当于$*2^x$
非负数 \>\> x ,相当于$/2^x$,下取整
非负数\>\>和\>\>\>结果是一样的
负数\>\>和\>\>\>结果是不一样的
~x=-x-1

注意：
可以这么写 : int num = 3231 | 6434;
可以这么写 : int num = 3231 & 6434;
不能这么写 : int num = 3231 || 6434;
不能这么写 : int num = 3231 && 6434;
因为 ||、&& 是 逻辑或、逻辑与，只能连接boolean类型
不仅如此，|、& 连接的两侧一定都会计算
而 ||、&& 有穿透性的特点，即确定了答案的确定性后面就不会继续了。

#### 为什么这么设计二进制
为了加法的逻辑是一套逻辑，没有条件转移。运用了溢出，一套逻辑就会运算很快，
5位的情况下
$8-4=8+(-4)=0b01000+0b11100=0b00100=4$

#### 为什么要这么设计加法
计算机中没有=,-,\*,/的概念，只有位运算的概念。而加法是+,-,\*,/里面最简单的，会通过+和位运算来解决-,\*,/的问题

#### 通过位运算来求出每个数的二进制
如何求出一个数的某一位二进制？
(value>>i)&1
i就是要知道的位数。value>>i就是把value右移了i位，此时这个第i位就被放到了0位。而1又是000001，那么此时计算结果就之和第0位有关，跟别的就无关了。
同时，int，long long的二进制位数是固定的，只要跑个for循环，就可以输出每个数的二进制了。
```c++
void printBinary(int value) {
    // 从最高位（第31位，即符号位）开始遍历到最低位（第0位）
    for (int i = 31; i >= 0; i--) {
        // 将 value 右移 i 位，然后与 1 进行按位与运算，得到该位的值（0 或 1）
        // 结果通过 cout 输出，不换行
        cout << ((value >> i) & 1);
    }
}
```

#### 通过位运算让某一位变1
参考通过位运算来求出每个数的二进制的思路。要让某一位从0变1，那就要用到|运算符。要将1移动到指定的位置，那就要用到<<运算符
`value |= (1 << x)`

#### 通过位运算让某一位变1
同理，要让某一位从1变0，那就要用到&运算符。要将1移动到指定的位置，那就要用到<<运算符。为了让别的位置不变，将这个数进行~
`value &= ~ (1 << x)`
