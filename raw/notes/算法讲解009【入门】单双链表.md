#### 单链表
单链表：每个节点至少有2个变量，当前节点的值是多少，下一个节点是哪个。最后一个节点连接-1，初始节点为0。
举例(下标|值|下一个节点):0|0|1 -> 1|24|5 -> 5|32|7 -> 7|63|-1
```c++
struct Node {  
    int val;  
    int next;  
    Node(int val=-1,int next=-1):val(val),next(next){}  
};
```
#### 单链表插入
单链表在某点后插入，就是将a->b变为a->b->c，我们只需要将添加点b的next设为c然后将a的next设为b就行了。
举例(跟着上一个例子):在下标1后面插入21
```c++
void insert(int x,int y) {     
    arr[idx]=Node(y,arr[x].next);  
    arr[x].next=idx++;  
}
```
#### 单链表删除
单链表将某点的后点删除，就是将a->b->c变为a->c，我们只需要将点a的next设为c就行了。
举例(跟着上一个例子):在下标1后面点删了
```c++
void erase(int x) {   
    arr[x].next=arr[arr[x].next].next;  
}
```
#### 例题
[B3631 单向链表 - 洛谷](https://www.luogu.com.cn/problem/B3631)
```c++
#include <bits/stdc++.h> using namespace std;  
struct Node {  
    int val;  
    int next;  
    Node(int val=-1,int next=-1):val(val),next(next){}  
};  
struct ListNode {  
    int idx;  
    vector<Node> arr;  
    vector<int> fin;  
    ListNode(int n) {  
        arr.resize(n+1);//会调用Node的无参构造  
        fin.resize((int)1e6+10);  
        idx=1;  
        arr[0]=Node(0,-1);  
    }  
    void insert(int x,int y) {  
        x=fin[x];  
        fin[y]=idx;  
        arr[idx]=Node(y,arr[x].next);  
        arr[x].next=idx++;  
    }  
    int coutNode(int x) {  
        if (arr[fin[x]].next==-1)  
            return 0;  
        else  
            return arr[arr[fin[x]].next].val;  
    }  
    void erase(int x) {  
        x=fin[x];  
        arr[x].next=arr[arr[x].next].next;  
    }  
};  
void solve() {  
    int q;  
    cin>>q;  
    ListNode listNode(q);  
    while (q--) {  
        int a,x,y;  
        cin>>a;  
        if (a==1) {  
            cin>>x>>y;  
            listNode.insert(x,y);  
        }else if (a==2){  
            cin>>x;  
            cout<<listNode.coutNode(x)<<endl;  
        }else {  
            cin>>x;  
            listNode.erase(x);  
        }  
    }  
}  
int main() {  
    ios::sync_with_stdio(false);  
    cin.tie(NULL);  
    cout.tie(NULL);  
    solve();  
    return 0;  
}
```
#### 双链表
双链表：在单链表的基础上，增加了上一个节点是哪个。此时每个节点至少有3个变量，当前节点的值是多少，下一个节点是哪个，上一个节点是哪个。最后一个节点连接0，初始节点为0。
举例(下标|值|下一个节点|上一个节点):0|0|1|7 -> 1|24|5|0 -> 5|32|7|1 -> 7|63|0|5
```c++
struct Node {  
    int val;  
    int next;  
    int pre;  
    Node(int val=-1,int next=-1,int pre=-1):val(val),next(next),pre(pre){}  
};
```
