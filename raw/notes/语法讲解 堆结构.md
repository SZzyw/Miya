#### 完全二叉树
完全二叉树和数组前缀范围来对应，大小，单独的变量size来控制。i的父亲节点：$(i-1)/2$，i的左孩子：$i*2 + 1$，i的右孩子：$i*2 + 2$
举例：\[3,5,3,6,2\]

#### 堆（大根堆，小根堆）
讲解只讲大根堆，小根堆同理
在完全二叉树的基础上，始终保持该节点比其子节点大与等于,此为大根堆，若不符合则需要进行操作。
##### 向上调整
对于节点i，若arr\[i\],若其比父节点大，则进行交换，并继续在新节点的位置与其父节点比较。
举例：\[5,6,3,6\]

```c++
    void heapInsert(vector<int> &arr, int i) {
        while (arr[i] > arr[(i - 1) / 2]) { //-1/2为0
            swap(arr[i], arr[(i - 1) / 2]);
            i = (i - 1) / 2;
        }
    }
```

#### 向下调整
对于节点i，若arr\[i\]比其子节点更小，则进行交换，并继续在新节点的位置与子父节点比较。注意是跟子结点中更大的哪个比
举例：\[6,6,5,3\]，arr\[0\]变为2.

```c++
    void heappify(vector<int> &arr, int i, int siz) {
        while ((i * 2 + 1) < siz) {
            int l = i * 2 + 1, r = l + 1;
            int best = l;
            if (r < siz && arr[l] < arr[r])
                best = r;
            if (arr[i] < arr[best])
                swap(arr[i], arr[best]);
            else
                break;
            i = best;
        }
    }
```

#### 时间复杂度
无论是向上调整还是向下调整，每次调整的最多的数为树的高度，而数组长度为n时，树的高度为$log n$ 
因此，时间复杂度为$log n$
