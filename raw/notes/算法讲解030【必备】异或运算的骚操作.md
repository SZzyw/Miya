#### 异或运算

异或运算复习：`0^0=0 1^1=0 0^1=1 1^0=1`

袋子里一共a个白球，b个黑球，每次从袋子里拿2个球，每个球每次被拿出机会均等
如果拿出的是2个白球、或者2个黑球，那么就往袋子里重新放入1个白球
如果拿出的是1个白球和1个黑球，那么就往袋子里重新放入1个黑球
那么最终袋子里一定会只剩1个球，请问最终的球是黑的概率是多少？用a和b来表达这个概率。

答案：
黑球的数量如果是偶数，最终的球是黑的概率是0%
黑球的数量如果是奇数，最终的球是黑的概率是100%
完全和白球的数量无关。为啥？异或运算的性质了解之后，就了解了。

**性质**
1.异或运算就是无进位相加   `0^0=0 1^1=0 0^1=1 1^0=1`  ->  `0+0=0 1+1=10=0 0+1=1 1+0=1`
2.异或运算满足交换律、结合律，也就是同一批数字，不管异或顺序是什么，最终的结果都是一个。   因为无进位相加，而加法最后的值只跟1的数量有关。
3.0异或任何数都是其本身，自己异或自己最后是0    0与任何数加法都保持不变。自己异或自己，1+1=0，0+0=0
4.整体异或和如果是x，整体中某个部分的异或和如果是y，那么剩下部分的异或和是`x^y`.       因为异或运算满足交换律、结合律

[268. 丢失的数字 - 力扣（LeetCode）](https://leetcode.cn/problems/missing-number/description/)
性质4

```c++
class Solution {
public:
    int missingNumber(vector<int> &nums) {
        int eorAll = 0, eorHas = 0;
        for (int i = 0; i < nums.size(); i++) {
            eorAll ^= nums[i];
            eorHas ^= i;
        }
        eorAll ^= nums.size();
        return eorAll ^ eorHas;
    }
};
```

[260. 只出现一次的数字 III - 力扣（LeetCode）](https://leetcode.cn/problems/single-number-iii/description/)
```c++
class Solution {
public:
    vector<int> singleNumber(vector<int> &nums) {
        int eor1 = 0, eor2 = 0;
        for (auto it: nums)
            eor1 ^= it;
        unsigned int rightOne = (unsigned int) eor1 & (-(unsigned int) eor1); //注意
        for (auto it: nums)
            if (it & rightOne)
                eor2 ^= it;
        return {eor1 ^ eor2, eor2};
    }
};
```
