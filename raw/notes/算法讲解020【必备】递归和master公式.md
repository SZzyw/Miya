数据结构：递归
#### 什么是递归
函数调用函数自己。
递归的base case：简单到不能再简单了。已经无法继续划分了。
思想：对于新手来说，递归去画调用图是非常重要的，有利于分析递归。
实际：递归不是玄学，底层是利用系统栈来实现的
任何递归函数都一定可以改成非递归，不用系统帮你压栈（系统栈空间），自己压栈呗（内存空间）
使用递归的方法来求一个数组的最值
举例：4，2，6，1
```c++
int maxValue(vector<int> &v, int l, int r) {  
    if (l == r)  
        return v[l];  
    int m = l + (r - l) / 2;  
    int lmax = maxValue(v, l, m);  
    int rmax = maxValue(v, m + 1, r);  
    return max(lmax, rmax);  
}
```

#### 时间复杂度和空间复杂度
所有子问题规模相同的递归才能用master公式，$T(n) = a * T(n/b) + O(n^c)$，a、b、c都是常数
比如上面的代码：有两个子函数，每次子问题的数据量是原数据量的一半,剩余的数据量是O(1)，因此$T(n) = 2 * T(n/2) + O(1)$

如果$\log_b a$  < c，复杂度为：O($n^c$)
如果$\log_b a$  > c，复杂度为：O($n^{log_b a}$)
如果$\log_b a$ == c，复杂度为：O($n^c * logn$)

补充$T(n) = 2 * T(n/2) + O(nlogn)$,复杂度为：O($n*log^2 n$)


每次递归都要调用系统栈，因此每多一层要多调用一个空间。
