2的幂肯定要考虑二进制
先考虑大于怎么做。
将二进制最左边的1以后都变成1，再+1就行了。
比如：000101100 -> 000111111 -> 001000000

```c++
class Near2power {
public:
    bool near2power(int n) {
        if (n <= 0)
            return 1;
        n |= n >> 1;
        n |= n >> 2;
        n |= n >> 4;
        n |= n >> 8;
        n |= n >> 16;
        return n + 1; //注意数据范围，INT_MAX会爆
    }
};
```

现在考虑等于的情况，等于情况只有刚好2的幂发生了变化，别的情况不变，再考虑之前的方法，我们可以把数-1，这样就行了。

```c++
class Near2power {
public:
    bool near2power(int n) {
        if (n <= 0)
            return 1;
        n -= 1;
        n |= n >> 1;
        n |= n >> 2;
        n |= n >> 4;
        n |= n >> 8;
        n |= n >> 16;
        return n + 1; //注意数据范围，INT_MAX会爆
    }
};
```
