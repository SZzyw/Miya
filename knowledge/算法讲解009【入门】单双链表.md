# 单双链表

链表中的每个节点保存自己的值，以及与其他节点的连接关系。本页使用数组 `arr` 保存节点，并用节点下标代替通常意义上的指针：`next` 表示下一个节点的下标，双链表还用 `pre` 表示上一个节点的下标。

## 单链表

单链表的每个节点至少有两个变量：当前节点的值，以及下一个节点是哪个。最后一个节点连接 `-1`，初始节点为 `0`。

例如，按照“下标 | 值 | 下一个节点”表示：

```text
0 | 0 | 1 -> 1 | 24 | 5 -> 5 | 32 | 7 -> 7 | 63 | -1
```

这里真正决定访问顺序的是 `next`：从下标 0 开始，依次访问节点 1、5、7。节点在 `arr` 中不必连续，只要 `next` 连接正确即可。

```cpp
struct Node {
    int val;
    int next;

    Node(int val = -1, int next = -1) : val(val), next(next) {
    }
};

void init() {
    // 建立 0 号初始节点；-1 表示当前没有后继。
    arr.push_back(Node(0, -1));
}
```

### 单链表插入

在某个节点后插入新节点，就是把：

```text
a -> c
```

变成：

```text
a -> b -> c
```

先让新节点 `b` 指向原来的 `c`，再让 `a` 指向 `b`。必须先保存原来的连接，否则修改 `a.next` 后可能找不到 `c`。

例如，在下标 `1` 后面插入值为 `21` 的节点：

```cpp
void insert(int x, int y) {  // 在 x 后面插入值 y
    // 新节点先接到 x 原来的后继，保留后半段链表。
    arr.push_back(Node(y, arr[x].next));

    // 再让 x 指向新节点，完成 x -> 新节点。
    arr[x].next = arr.size() - 1;
}
```

### 单链表删除

删除某个节点后面的节点，就是把：

```text
a -> b -> c
```

变成：

```text
a -> c
```

只需要让 `a` 的 `next` 跳过 `b`，直接指向 `c`。节点 `b` 即使仍然保存在 `arr` 中，也已经不再属于从链表头访问到的链表。

```cpp
void erase(int x) {  // 删除 x 后面的节点
    // 跳过 x 的后继，让 x 直接连接被删除节点的后继。
    arr[x].next = arr[arr[x].next].next;
}
```

## 双链表

双链表在单链表的基础上增加了“上一个节点是哪个”。每个节点至少有三个变量：当前节点的值、下一个节点和上一个节点。最后一个节点连接 `0`，初始节点为 `0`。

这里的 `0` 号节点是哨兵节点。空链表时，哨兵的 `next` 和 `pre` 都是 `0`；非空时，第一个节点的 `pre` 和最后一个节点的 `next` 都连接到 `0`。

例如，按照“下标 | 值 | 下一个节点 | 上一个节点”表示：

```text
0 | 0 | 1 | 7 -><- 1 | 24 | 5 | 0 -><- 5 | 32 | 7 | 1 -><- 7 | 63 | 0 | 5 -><-
```

```cpp
struct Node {
    int val;
    int next;
    int pre;

    Node(int val = -1, int next = -1, int pre = -1)
        : val(val), next(next), pre(pre) {
    }
};
```

### 双链表插入

在某个节点后插入新节点，就是把：

```text
a -><- c
```

变成：

```text
a -><- b -><- c
```

需要同时设置四个连接关系中的关键三处：新节点 `b` 的 `next` 为 `c`、`pre` 为 `a`，然后令 `a.next` 为 `b`、`c.pre` 为 `b`。

```cpp
void insert(int x, int y) {  // 在 x 后面插入值 y
    // 先保存原来的后继，避免修改连接后找不到 c。
    int z = arr[x].next;

    // 新节点同时记录前驱 x 和后继 z。
    arr.push_back(Node(y, x, z));

    // 把新节点接入 x 与 z 之间，维护两个方向的连接。
    arr[z].pre = arr.size() - 1;
    arr[x].next = arr.size() - 1;
}
```

### 双链表删除

删除节点 `b`，就是把：

```text
a -><- b -><- c
```

变成：

```text
a -><- c
```

先通过 `b.pre` 找到 `a`，再通过 `b.next` 找到 `c`，最后同时令 `a.next = c`、`c.pre = a`。两个方向都要修改，否则双链表会出现连接不一致。

```cpp
void erase(int x) {
    // y 保存待删除节点；x 改为它的前驱，z 保存它的后继。
    int y = x;
    x = arr[y].pre;
    int z = arr[y].next;

    // 让删除节点两侧直接相连，同时维护 next 和 pre。
    arr[x].next = z;
    arr[z].pre = x;
}
```

## 时间复杂度

在已经知道节点位置的情况下，单链表和双链表的插入、删除都只修改常数个连接，因此时间复杂度都是 `O(1)`。如果需要从头沿 `next` 查找节点，最坏需要遍历整个链表，时间复杂度为 `O(n)`。

使用 `arr` 保存节点需要 `O(n)` 额外空间；如果通过 `fin` 记录元素编号到节点下标的映射，映射数组也需要按元素编号范围分配空间。
