# 选择、冒泡、插入排序

## 选择

选择排序的核心是：

- 在 i 到 n - 1 范围内找到最小值；
- 把这个最小值放到 i 位置；
- 然后继续处理 i + 1 到 n - 1 的范围。

每完成一轮，数组前面就多出一个已经确定的最小值。

```cpp
void selectionSort(vector<int> &v) {
    int n = v.size();

    for (int i = 0; i < n; ++i) {
        int min_j = i;

        for (int j = i + 1; j < n; ++j) {
            if (v[j] < v[min_j]) {
                min_j = j;
            }
        }

        // 把未排序范围中的最小值放到当前位置
        swap(v[i], v[min_j]);
    }
}
```

## 冒泡

冒泡排序的核心是：

- 在 0 到 i 范围内比较相邻元素；
- 较大的数不断向右移动；
- 一轮结束后，当前范围的最大值来到 i 位置；
- 下一轮只需要处理 0 到 i - 1 的范围。

```cpp
void bubbleSort(vector<int> &v) {
    int n = v.size();

    for (int i = n - 1; i >= 0; --i) {
        for (int j = 0; j < i; ++j) {
            if (v[j] > v[j + 1]) {
                swap(v[j], v[j + 1]);
            }
        }
    }
}
```

## 插入

插入排序维护一个已经有序的区间。开始时第一个元素天然有序；每次取出新的元素，从右向左寻找位置，把比它大的元素向右移动，再把它插入空出来的位置。

```cpp
void insertionSort(vector<int> &v) {
    int n = v.size();

    for (int i = 1; i < n; ++i) {
        int value = v[i];
        int j = i - 1;

        while (j >= 0 && v[j] > value) {
            v[j + 1] = v[j];
            --j;
        }

        v[j + 1] = value;
    }
}
```

## 复杂度

- 选择排序：最好、平均、最坏都是 O(n²)，额外空间 O(1)。
- 冒泡排序：平均和最坏是 O(n²)，额外空间 O(1)。
- 插入排序：最好是 O(n)，平均和最坏是 O(n²)，额外空间 O(1)。
