# 二进制和位运算

## 二进制的概念

十进制的每一位代表一个 10 的幂。例如：

$103=10^0\times3+10^1\times0+10^2\times1$

二进制的每一位代表一个 2 的幂。例如：

$101=2^0\times1+2^1\times0+2^2\times1$

计算机使用二进制表示和处理数据。C++ 把底层的二进制细节封装成了整数、字符等类型，但在需要时，我们仍然可以直接操作整数的每一位。

在数的前面加上 0b，可以明确表示这是一个二进制字面量，例如 0b101。

## 位的概念

“位”表示二进制数有多少个二进制数字。

例如，十进制的 1848 是 4 位数；二进制的 0b1011 也是 4 位数。讨论有符号数时，还要注意最高位可能被当作符号位。

## 正数十进制转二进制

对于一个正数，反复除以 2：

- 每次除法得到的余数，就是当前还没有确定的最低位；
- 商继续参与下一轮除法；
- 所有余数从后往前读取，就得到从高位到低位的二进制表示。

以 5 为例：

$5/2=2\cdots1$

$2/2=1\cdots0$

$1/2=0\cdots1$

因此，$5=0b101$。如果使用 5 位表示，并补充一个符号位 0，就写成 0b00101。

下面的代码固定输出 5 位，适合演示 5 位二进制的表示过程。

```cpp
void func(int value) {
    stack<int> s;

    // 反复除以 2，把余数从低位到高位压入栈
    while (value != 0) {
        s.push(value % 2);
        value /= 2;
    }

    // 固定输出 5 位，不足的高位补 0
    while (s.size() < 5) {
        s.push(0);
    }

    // 栈顶是最高位，依次弹出即可得到正确顺序
    while (s.size() != 0) {
        cout << s.top();
        s.pop();
    }
}
```

## 无符号数据范围计算

在常见竞赛环境中：

- int 占 4 个字节，即 32 位；
- long long 占 8 个字节，即 64 位。

如果有 w 位，并且每一位都用来表示数值，那么最小值是 0，最大值是所有位都为 1，也就是：

$0\sim2^w-1$

因此常见无符号类型的范围是：

- unsigned int：$0\sim2^{32}-1$
- unsigned long long：$0\sim2^{64}-1$

## 负数十进制转二进制

有符号二进制数通常使用补码表示。补码的一个重要特点是：正数和负数可以使用同一套加法逻辑。

在固定的位数下，求负数的补码可以这样理解：

1. 先取绝对值；
2. 减去 1；
3. 求出结果的二进制；
4. 按位取反。

以 5 位表示 -5 为例：

$-5\rightarrow5\rightarrow4$

$4$ 的 5 位表示是 $00100$，按位取反后得到 $11011$，所以：

$-5=0b11011$

下面的代码固定输出 5 位，适合演示 5 位补码；它不是任意位宽的通用转换函数。

```cpp
void func(int value) {
    // 将负数转换为“绝对值减 1”，再对得到的二进制逐位取反
    value = -value - 1;

    stack<int> s;

    // 对转换后的非负数除二取余
    while (value != 0) {
        s.push(value % 2);
        value /= 2;
    }

    // 固定输出 5 位，不足的高位补 0
    while (s.size() < 5) {
        s.push(0);
    }

    // 逐位取反后输出
    while (s.size() != 0) {
        if (s.top() == 1) {
            cout << 0;
        } else {
            cout << 1;
        }
        s.pop();
    }
}
```

## 有符号最小值的特殊性

以 4 位二进制为例，最高位是符号位。这里的 `0b1000` 有两种解释：

- 按无符号数解释，`0b1000` 是十进制的 `8`；
- 按 4 位有符号补码解释，`0b1000` 是十进制的 `-8`。

为什么同一组二进制位会表示 `-8`？按照前面负数转换的过程，先把 `8` 减 1，得到 `7`，再写成 4 位二进制 `0b0111`，最后逐位取反，就得到 `0b1000`。因此，`0b1000` 就是 4 位有符号数的最小值。

这说明了一个特殊点：在固定位数的有符号数中，最小值的绝对值没有对应的正数表示。4 位有符号数的范围是：

$-2^{3}\sim2^{3}-1=-8\sim7$

其中正数的最高位必须为 `0`，最高位为 `1` 的位模式会按照补码规则解释为负数。

## 带符号数据范围计算

对于 w 位有符号补码整数，数据范围是：

$-2^{w-1}\sim2^{w-1}-1$

因此，在常见竞赛环境中：

- signed int：$-2^{31}\sim2^{31}-1$
- signed long long：$-2^{63}\sim2^{63}-1$

原始转换代码固定演示 5 位，不能直接拿来处理任意位宽的 int 或 long long。

## 16 进制

在数的前面加上 0x，可以表示十六进制字面量。

十六进制中：

- 0 到 9 仍然使用数字；
- 10 到 15 分别使用 a、b、c、d、e、f 表示。

十进制转十六进制与十进制转二进制的原理相同，都是不断除以进制并记录余数。

二进制和十六进制之间可以快速转换：4 位二进制对应 1 位十六进制。

## 常见的位运算

### 按位取反

~ 会把每一位 0 变成 1，把每一位 1 变成 0。在固定 5 位的例子中：

~ 0b10010 = 0b01101

对补码整数来说，按位取反还满足：

~x = -x - 1

### 左移和右移

<< 将二进制整体向左移动，右侧补 0。

对于非负数，左移 x 位通常相当于乘以 $2^x$，但左移溢出时不能继续这样理解。

`>>` 是 C++ 的右移运算符。对于非负数，右移 x 位相当于除以 $2^x$ 后向下取整。

C++ 没有 `>>>` 运算符。如果需要逻辑右移，应使用无符号类型；带符号负数的右移不要按无符号数的规则想当然。

### 按位与、按位异或、按位或

- &：两位都为 1 时结果才为 1。
- ^：两位相同为 0，不同为 1。
- |：只要有一位为 1，结果就是 1。

例如：

0b10010 & 0b01011 = 0b00010

0b10010 ^ 0b01011 = 0b11001

0b10010 | 0b01011 = 0b11011

| 和 & 是按位运算，|| 和 && 是逻辑运算：

- 可以写 int num = 3231 | 6434；
- 可以写 int num = 3231 & 6434；
- 不能把 ||、&& 当作 |、& 使用；
- |、& 两侧都会计算；
- ||、&& 具有短路特性，确定结果后可能不再计算右侧。

## 为什么要这样设计二进制

使用固定宽度的补码后，加法、减法可以共用一套底层加法逻辑。计算过程中允许溢出，结果只保留固定宽度的低位。

例如在 5 位表示下：

$8-4=8+(-4)=0b01000+0b11100=0b00100=4$

## 为什么要这样设计加法

计算机底层通过逻辑门和位运算实现加法。减法、乘法和除法等更复杂的整数运算，也可以建立在加法和位运算之上。

## 通过位运算求出每个数的二进制

如果想知道 value 的第 i 位，可以使用：

`(value >> i) & 1`

`value >> i` 会把原来的第 i 位移动到最低位；再与 `1` 做按位与，就只保留最低位，得到 `0` 或 `1`。

int 和 long long 的位宽是固定的，因此可以从最高位循环到最低位，逐位输出。

```cpp
void printBinary(int value) {
    // int 按 32 位表示，从最高位（第 31 位）输出到最低位
    for (int i = 31; i >= 0; i--) {
        cout << ((value >> i) & 1);
    }
}
```

## 通过位运算让某一位变成 1

要让第 x 位变成 1：

1. 先把 1 左移 x 位，得到只在第 x 位为 1 的掩码；
2. 再与原数做按位或。

`value |= (1 << x)`

## 通过位运算让某一位变成 0

要让第 x 位变成 0：

1. 先把 1 左移 x 位；
2. 按位取反，让第 x 位为 0、其他位为 1；
3. 与原数做按位与。

`value &= ~(1 << x)`

## 其他

位运算中的溢出通常不会由计算机自动提醒，需要由程序员根据数据范围自行保证。
