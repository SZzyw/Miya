# 二分搜索

二分搜索的核心不是“数组有序”这四个字本身，而是：每次根据题目提供的规律，排除一半不可能的范围。

最常见的场景是在升序数组中查找元素。此时，中点与目标值的大小关系可以直接决定答案在哪一侧。但二分搜索也可以用于整体无序的数组，只要能够判断某一侧一定存在答案，例如“寻找峰值”中的上坡性质。

## 在有序数组中确定 num 是否存在

在升序数组中查找 `num` 时，维护一个仍然可能包含答案的左闭右闭区间 `[l, r]`，每次检查其中点 `m`：

- 如果 `arr[m] == num`，已经找到目标值。
- 如果 `arr[m] < num`，由于数组升序，`m` 及其左侧都小于 `num`，答案只可能在右侧。
- 如果 `arr[m] > num`，由于数组升序，`m` 及其右侧都大于 `num`，答案只可能在左侧。

每次判断都会舍弃当前区间的一半。区间为空时仍未找到目标值，说明 `num` 不存在。

### 示例：查找 13 是否存在

数组为：

```text
下标：0  1  2  3   4   5   6   7
数值：1  3  5  9  13  15  23  25
```

查找过程如下：

1. 初始区间为 `[0, 7]`，中点为 `m = (0 + 7) / 2 = 3`。`arr[3] = 9 < 13`，所以答案只可能在右侧，区间变为 `[4, 7]`。
2. 当前区间为 `[4, 7]`，中点为 `m = (4 + 7) / 2 = 5`。`arr[5] = 15 > 13`，所以答案只可能在左侧，区间变为 `[4, 4]`。
3. 当前只剩下下标 4，`arr[4] = 13`，查找成功。

```cpp
bool exist(vector<int> &arr, int num) {
    // 空数组不可能包含目标值。
    if (arr.size() == 0) {
        return false;
    }

    // 使用左闭右闭区间 [l, r] 保存仍可能包含目标值的位置。
    int l = 0;
    int r = arr.size() - 1;

    while (l <= r) {
        // 用差值计算中点，避免 l + r 过大时溢出。
        int m = l + (r - l) / 2;

        if (arr[m] == num) {
            // 中点就是目标值，查找成功。
            return true;
        }

        if (arr[m] < num) {
            // m 及其左侧都不可能是答案，只保留右半区。
            l = m + 1;
        } else {
            // m 及其右侧都不可能是答案，只保留左半区。
            r = m - 1;
        }
    }

    // 区间为空仍未找到，说明目标值不存在。
    return false;
}
```

## 在有序数组中找大于等于 num 的最左位置

这次不是查找一个等于 `num` 的元素，而是查找所有满足 `arr[i] >= num` 的位置中下标最小的那个。

仍然使用二分搜索，但“找到满足条件的位置”后不能立即返回，因为左侧可能还有更靠前的满足条件位置：

- 如果 `arr[m] < num`，`m` 及其左侧都不满足条件，只能向右搜索。
- 如果 `arr[m] >= num`，`m` 可以作为候选答案，同时继续向左搜索，尝试找到更靠前的位置。

因此需要额外维护 `ans`，记录当前已经找到的最左候选位置。搜索结束时，`ans` 就是答案；如果始终没有找到满足条件的位置，返回 `-1`。

### 示例：查找第一个大于等于 15 的位置

数组为：

```text
下标：0  1  2  3  4   5   6   7
数值：3  6  6  7  9  13  15  19
```

查找过程如下：

1. 区间为 `[0, 7]`，中点 `m = 3`，`arr[3] = 7 < 15`，所以去右侧，区间变为 `[4, 7]`。
2. 区间为 `[4, 7]`，中点 `m = 5`，`arr[5] = 13 < 15`，所以继续去右侧，区间变为 `[6, 7]`。
3. 区间为 `[6, 7]`，中点 `m = 6`，`arr[6] = 15 >= 15`。先记录 `ans = 6`，再向左检查是否存在更靠前的答案，区间变为 `[6, 5]`。
4. 区间为空，返回 `ans = 6`。下标 6 对应的元素是 15，它就是第一个大于等于 15 的元素。

```cpp
// 在升序数组 arr 中查找第一个大于等于 nums 的元素下标。
// 如果不存在这样的元素，则返回 -1。
int findLeft(vector<int> &arr, int nums) {
    int l = 0;
    int r = arr.size() - 1;
    int ans = -1;

    while (l <= r) {
        int m = l + (r - l) / 2;

        if (arr[m] >= nums) {
            // 当前点满足条件，但左侧可能还有更靠前的答案。
            ans = m;
            r = m - 1;
        } else {
            // m 及其左侧都不满足条件，只能向右搜索。
            l = m + 1;
        }
    }

    // 返回最靠左的候选位置；没有候选时返回 -1。
    return ans;
}
```

## 在有序数组中找小于等于 num 的最右位置

这次要找的是所有满足 `arr[i] <= num` 的位置中下标最大的那个。

二分判断与上一个问题对称：

- 如果 `arr[m] <= num`，`m` 可以作为候选答案，但右侧可能还有更靠后的满足条件位置，因此记录 `ans` 后继续向右搜索。
- 如果 `arr[m] > num`，`m` 及其右侧都不满足条件，只能向左搜索。

```cpp
// 在升序数组 arr 中查找最后一个小于等于 nums 的元素下标。
// 如果不存在这样的元素，则返回 -1。
int findRight(vector<int> &arr, int nums) {
    int l = 0;
    int r = arr.size() - 1;
    int ans = -1;

    while (l <= r) {
        // 用差值计算中点，避免 l + r 过大时溢出。
        int m = l + (r - l) / 2;

        if (arr[m] <= nums) {
            // 当前点满足条件，但右侧可能还有更靠后的答案。
            ans = m;
            l = m + 1;
        } else {
            // m 及其右侧都不满足条件，只能向左搜索。
            r = m - 1;
        }
    }

    // 返回最靠右的候选位置；没有候选时返回 -1。
    return ans;
}
```

## 二分搜索复杂度分析

- 时间复杂度：`O(log n)`。每轮都会把候选区间缩小到原来的一半。
- 额外空间复杂度：`O(1)`。二分过程只使用左右边界、中点和候选答案等常数个变量。
