# 二分搜索

二分搜索的核心是：每次利用题目中的规律，排除一半不可能的范围。最常见的情况是在有序数组中查找，也可以利用“某一侧一定能找到答案”的性质处理无序数组。

## 在有序数组中确定 num 是否存在

在有序数组中查找一个数时，可以先看中间位置的数：

- 如果中间数就是 num，查找成功。
- 如果中间数小于 num，那么中间数左边的数也都小于 num，答案只可能在右边。
- 如果中间数大于 num，那么中间数右边的数也都大于 num，答案只可能在左边。

每次都排除一半范围，直到找到 num，或者查找区间变为空。

### 示例：查找 13 是否存在

数组为：

```text
下标：0  1  2  3   4   5   6   7
数值：1  3  5  9  13  15  23  25
```

查找过程：

1. 初始区间是 [0, 7]，中点为 m = (0 + 7) / 2 = 3。arr[3] = 9，因为 9 < 13，所以答案只可能在右侧，区间缩小为 [4, 7]。
2. 当前区间是 [4, 7]，中点为 m = (4 + 7) / 2 = 5。arr[5] = 15，因为 15 > 13，所以答案只可能在左侧，区间缩小为 [4, 4]。
3. 当前只剩下下标 4，arr[4] = 13，查找成功。

### 代码

```cpp
bool exist(vector<int> &arr, int num) {
    // 空数组中没有目标值
    if (arr.size() == 0) {
        return false;
    }

    // 使用左闭右闭区间 [l, r] 保存仍可能包含目标值的范围
    int l = 0;
    int r = arr.size() - 1;

    while (l <= r) {
        // 用差值计算中点，避免 l + r 过大时溢出
        int m = l + (r - l) / 2;

        if (arr[m] == num) {
            return true;
        }

        if (arr[m] < num) {
            // 数组有序，mid 及其左侧都不可能是答案
            l = m + 1;
        } else {
            // 数组有序，mid 及其右侧都不可能是答案
            r = m - 1;
        }
    }

    return false;
}
```

时间复杂度为 O(log n)，额外空间复杂度为 O(1)。

## 在有序数组中找 >= num 的最左位置

这次不是找到一个等于 num 的位置就结束，而是要找到所有满足 arr[i] >= num 的位置中，下标最小的那个。

每次取中点：

- 如果 arr[m] < num，中点和左侧都不满足条件，只能去右侧查找。
- 如果 arr[m] >= num，中点已经满足条件，可以先把它记为候选答案；但左侧可能还有更靠前的答案，所以继续向左查找。

### 示例

数组为：

```text
下标：0  1  2  3  4   5   6   7
数值：3  6  6  7  9  13  15  19
```

查找第一个大于等于 15 的位置：

1. 初始区间是 [0, 7]，中点 m = 3，arr[3] = 7 < 15，所以去右侧，区间变为 [4, 7]。
2. 当前区间是 [4, 7]，中点 m = 5，arr[5] = 13 < 15，所以继续去右侧，区间变为 [6, 7]。
3. 当前区间是 [6, 7]，中点 m = 6，arr[6] = 15 >= 15。先记录 ans = 6，再去左侧检查是否还有更靠前的答案，区间变为 [6, 5]。
4. 区间为空，返回 6。下标 6 对应的数是 15，它就是第一个大于等于 15 的数。

### 代码

```cpp
// 在升序数组 arr 中查找第一个大于等于 nums 的元素下标
// 如果不存在这样的元素，则返回 -1
int findLeft(vector<int> &arr, int nums) {
    int l = 0, r = arr.size() - 1;
    int ans = -1;

    while (l <= r) {
        int m = l + (r - l) / 2;

        if (arr[m] >= nums) {
            // 当前下标满足条件，但左侧可能还有更靠前的答案
            ans = m;
            r = m - 1;
        } else {
            // mid 及左侧都不满足条件，只能去右侧
            l = m + 1;
        }
    }

    return ans;
}
```

时间复杂度为 O(log n)，额外空间复杂度为 O(1)。

## 在有序数组中找 <= num 的最右位置

这次要找的是所有满足 arr[i] <= num 的位置中，下标最大的那个。

每次取中点：

- 如果 arr[m] <= num，中点满足条件，可以先记录为候选答案；但右侧可能还有更靠后的答案，所以继续向右查找。
- 如果 arr[m] > num，中点和右侧都不满足条件，只能去左侧查找。

### 代码

```cpp
// 在升序数组 arr 中查找最后一个小于等于 nums 的元素下标
// 如果不存在这样的元素，则返回 -1
int findRight(vector<int> &arr, int nums) {
    int l = 0, r = arr.size() - 1;
    int ans = -1;

    while (l <= r) {
        // 用差值计算中点，避免 l + r 过大时溢出
        int m = l + (r - l) / 2;

        if (arr[m] <= nums) {
            // 当前下标满足条件，但右侧可能还有更靠后的答案
            ans = m;
            l = m + 1;
        } else {
            // mid 及右侧都不满足条件，只能去左侧
            r = m - 1;
        }
    }

    return ans;
}
```

时间复杂度为 O(log n)，额外空间复杂度为 O(1)。

## 二分搜索不一定发生在有序数组上

二分搜索更一般的思想是：找到一种判断方法，使我们知道答案一定在左侧或右侧，然后排除另一半范围。

在“寻找峰值”这道题中，数组不要求整体有序，但可以利用下面的性质：

- 如果中间位置是峰值，直接返回它。
- 如果左邻居比中间值大，向左走；从中间位置向左的方向上一定能找到峰值。
- 否则向右走；从中间位置向右的方向上一定能找到峰值。

题目给出的峰值定义和边界条件保证了这种排除方式成立。
