# 递归和 Master 公式

## 什么是递归

递归就是函数调用函数自己。一个递归函数必须有一个 **base case（递归终止条件）**：问题已经简单到不能再简单，无法继续划分时，直接给出结果。

对于刚接触递归的同学，画递归调用图非常重要。把一次函数调用拆成哪些更小的调用、每个调用什么时候返回画出来，能够帮助我们理解递归的执行过程，而不是把递归当成玄学。

递归在底层依靠系统栈实现。每调用一层函数，系统就会把这一层调用需要保存的信息压入栈中；这一层执行结束后，再从栈中恢复上一层的执行状态。

从实现角度看，任何递归函数都可以改写成非递归版本：不让系统帮我们压入系统栈，而是自己使用普通内存维护一个栈，手动保存和恢复每层调用所需要的状态。

## 使用递归求数组的最值

下面用递归求一个数组区间中的最大值。函数 `maxValue(v, l, r)` 表示：返回数组 `v` 在下标区间 `[l, r]` 内的最大值。

- 当 `l == r` 时，区间中只有一个元素，它就是这个区间的最大值，这就是 base case。
- 当区间中有多个元素时，把区间从中间分成左右两部分。
- 分别递归求出左半部分最大值 `lmax` 和右半部分最大值 `rmax`。
- 整个区间的最大值就是 `lmax` 与 `rmax` 中较大的一个。

### 示例：数组 `4，2，6，1`

初始调用处理下标区间 `[0, 3]`，中点为 `m = 1`，因此分成 `[0, 1]` 和 `[2, 3]`：

1. 处理左区间 `[0, 1]`：继续分成 `[0, 0]` 和 `[1, 1]`，得到 `max(4, 2) = 4`。
2. 处理右区间 `[2, 3]`：继续分成 `[2, 2]` 和 `[3, 3]`，得到 `max(6, 1) = 6`。
3. 合并左右结果：`max(4, 6) = 6`。

因此，数组 `4，2，6，1` 的最大值是 `6`。对应的调用关系可以写成：

```text
maxValue([0, 3])
├── maxValue([0, 1])
│   ├── maxValue([0, 0]) -> 4
│   └── maxValue([1, 1]) -> 2
│   -> 4
└── maxValue([2, 3])
    ├── maxValue([2, 2]) -> 6
    └── maxValue([3, 3]) -> 1
    -> 6
-> 6
```

```cpp
int maxValue(vector<int> &v, int l, int r) {
    // 区间只剩一个元素时，直接返回该元素，递归在这里停止继续划分。
    if (l == r)
        return v[l];

    // 将当前区间分成左右两半；用差值计算中点可避免 l + r 过大。
    int m = l + (r - l) / 2;

    // 先分别得到左右子区间的最大值，再比较两个子问题的结果。
    int lmax = maxValue(v, l, m);
    int rmax = maxValue(v, m + 1, r);
    return max(lmax, rmax);
}
```

## 时间复杂度和空间复杂度

### Master 公式的适用形式

只有当递归产生的子问题规模相同，才能使用 Master 公式。常见形式为：

$$
T(n) = a \cdot T\left(\frac{n}{b}\right) + O(n^c)
$$

其中 `a`、`b`、`c` 都是常数：

- `a`：每次递归产生的子问题数量；
- `n / b`：每个子问题的规模；
- `O(n^c)`：本层递归调用之外的剩余工作。

根据 `\log_b a` 与 `c` 的大小关系，可以得到：

- 如果 `\log_b a < c`，复杂度为 `O(n^c)`；
- 如果 `\log_b a > c`，复杂度为 `O(n^{\log_b a})`；
- 如果 `\log_b a = c`，复杂度为 `O(n^c \log n)`。

### 套用到数组最值代码

上面的代码中，每次调用会产生两个子函数调用：

- 左子问题处理原区间的一半；
- 右子问题处理原区间的一半；
- 除递归调用之外，只进行中点计算、比较和返回等常数级工作，即 `O(1)`。

因此它的递推式是：

$$
T(n) = 2 \cdot T\left(\frac{n}{2}\right) + O(1)
$$

此时 `a = 2`、`b = 2`、`c = 0`，有 `\log_2 2 = 1 > 0`，所以时间复杂度为 `O(n)`。直观上看，递归调用图的每一层合计处理的区间规模都是线性级别，所有层合起来仍然是线性级别。

### 补充递推式

教练已确认补充递推式为：

$$
T(n) = 2 \cdot T\left(\frac{n}{2}\right) + O(n\log n)
$$

对应的复杂度为：

$$
O(n\log^2 n)
$$

可以从递归树理解这个结论：第 0 层的额外工作是 `O(n log n)`，下一层两个子问题合计的额外工作是 `O(n log(n/2))`，之后每层的总规模仍为 `n`，但对数项逐层减少。递归深度为 `O(log n)`，把各层的工作相加后得到 `O(n log^2 n)`。

### 递归的额外空间

每次递归调用都需要使用系统栈，因此递归每增加一层，就需要多占用一份栈空间。

对于上面的数组最值递归，每次都把问题规模缩小为原来的一半，递归深度为 `O(log n)`，所以额外的系统栈空间复杂度为 `O(log n)`。这里的空间复杂度指输入数组之外，为递归调用维护的额外空间。
