# 随机快速排序

前置知识：[[算法讲解020【必备】递归和master公式]]。

快速排序使用分治思想完成排序。对于当前下标区间 `[l, r]`，先随机选择一个数 `x`，再按照 `x` 对区间进行划分：把小于等于 `x` 的数放到左侧，把大于 `x` 的数放到右侧。划分完成后，继续递归处理左右两段。

本页先介绍每次只确定一个位置的基本写法，再介绍把等于 `x` 的元素集中到中间的优化写法。后面的模板题代码使用优化后的三路划分。

## 快速排序

基本过程可以分成三步：

1. 在当前区间 `[l, r]` 中随机选出一个数 `x` 作为划分值。
2. 调整数组，使小于等于 `x` 的元素位于左侧，大于 `x` 的元素位于右侧，并把一个等于 `x` 的元素放到分界位置。
3. 分别递归处理分界位置左边和右边的区间。

### `partition` 的过程

代码中的 `j` 表示下一个应该放入“小于等于 `x` 的区域”的位置。扫描下标 `i` 从 `l` 到 `r`：

- 如果 `arr[i] <= x`，就把它交换到 `j` 位置，然后让 `j` 向右移动；
- 如果 `arr[i] > x`，它暂时留在右侧，不增加 `j`；
- `now` 记录扫描过程中某个等于 `x` 的元素被放入的位置。

扫描结束后，`j` 原本指向小于等于 `x` 区域的后一格，执行 `j--` 后就得到这个区域的最后位置。再把 `arr[now]` 与 `arr[j]` 交换，就能保证返回的 `j` 位置存放一个 `x`。于是，`j` 左侧的元素都满足 `<= x`，右侧的元素都满足 `> x`，可以把 `j` 当作已经确定的位置。

`x` 是从当前区间中随机取出的，所以当前区间中一定存在至少一个等于 `x` 的元素，`now` 能够被更新。这个实现的前提是 `partition` 只能接收当前区间中实际存在的划分值。

### 示例：`5，3，6，7，3`

由于枢轴是随机选择的，第一次划分的具体结果取决于随机选中的数。下面选取这个数组中已有的 `3` 作为一次可能的 `x`，只用于展开划分过程：

```text
初始数组：5，3，6，7，3
划分值：  x = 3
```

从左到右扫描：

1. `5 > 3`，它不属于左侧的“小于等于 `x`”区域，暂时留在未处理范围中。
2. 第一个 `3 <= 3`，把它放入左侧区域。
3. `6 > 3`、`7 > 3`，都留在右侧的未处理范围中。
4. 最后一个 `3 <= 3`，也把它放入左侧区域，并更新 `now`。

扫描和最后的交换完成后，可以得到满足分区条件的一种排列：

```text
[3] [3] [6，7，5]
     ↑
   mid = 1
```

其中下标 `1` 的 `3` 是本次 `partition` 返回的分界元素。左侧区间 `[0, 0]` 和右侧区间 `[2, 4]` 继续递归排序；递归结束后，整个数组得到有序结果：

```text
3，3，5，6，7
```

实际运行时随机选到的 `x` 可能是数组中的其他值，因此第一次分割的位置和中间排列可能不同，但每次划分都遵循“小于等于 `x` 在左、大于 `x` 在右”的条件。

### 教练代码：每次确定一个位置

```cpp
struct QuickSort {
    vector<int> &arr;

    QuickSort(vector<int> &arr) : arr(arr) {
    }

    int partition(int l, int r, int x) {
        // j 指向下一个应该放入“小于等于 x”区域的位置。
        int j = l, now = -1;
        for (int i = l; i <= r; i++) {
            if (arr[i] <= x) {
                // 将当前满足条件的元素交换到左侧区域的末尾。
                swap(arr[i], arr[j]);
                if (arr[j] == x)
                    // x 来自当前区间，记录一个被放入左侧区域的 x。
                    now = j;
                j++;
            }
        }

        // j 原本指向 <= x 区域的后一格，回退到该区域最后位置。
        j--;
        // 把一个 x 放到最终分界位置，返回这个已经确定的位置。
        swap(arr[now], arr[j]);
        return j;
    }

    void quickSort(int l, int r) {
        // 区间至多一个元素时已经有序，不需要继续递归。
        if (l >= r)
            return;

        // 每个递归区间都重新随机选择一个划分值。
        int x = arr[rand() % (r - l + 1) + l];
        int mid = partition(l, r, x);

        // 分界元素已经就位，只递归处理它左右两侧。
        quickSort(l, mid - 1);
        quickSort(mid + 1, r);
    }
};
```

这份写法每次只把一个等于 `x` 的元素固定在分界位置。其他等于 `x` 的元素仍可能留在左侧递归区间中，因此重复值较多时，递归区间不一定能明显缩小。

## 优化

基本写法每次只能确定一个数的位置。为了让重复出现的划分值不再被重复递归，可以把当前区间分成三段：

- 左段：小于 `x`；
- 中段：等于 `x`；
- 右段：大于 `x`。

中段中的所有数都已经满足相对顺序要求，不需要再递归处理。因此只需要把小于 `x` 的数向左移动、大于 `x` 的数向右移动。

代码用 `first` 和 `last` 表示中间段的边界。划分结束时满足：

```text
[l, first - 1]       < x
[first, last]        = x
[last + 1, r]        > x
```

`partition` 返回 `{first, last}`，递归只处理 `[l, first - 1]` 和 `[last + 1, r]`。

### 示例：`1，2，2，1，3`

为了展示重复值如何被集中到中间，下面选取数组中已有的 `2` 作为一次可能的 `x`：

```text
初始数组：1，2，2，1，3
划分值：  x = 2
```

扫描过程中：

1. 遇到第一个 `1 < 2`，把它放入左段。
2. 遇到两个 `2`，它们属于中段，暂时保持在中间区域。
3. 遇到第二个 `1 < 2`，把它交换到左段，中段边界向右扩展。
4. 遇到 `3 > 2`，把它交换到右段。交换后需要继续检查换回当前位置的元素；它最终会被归入左段或中段。

划分完成后，数组可以表示为：

```text
[1，1] [2，2] [3]
  <2    =2   >2
```

此时 `first = 2`、`last = 3`，返回 `{2, 3}`。下标区间 `[2, 3]` 中的两个 `2` 不再递归；只需要继续处理左侧 `[0, 1]` 和右侧 `[4, 4]`。这里展示的是三段划分后的区域关系，具体元素交换顺序取决于代码扫描过程。

### 为什么大于 `x` 时必须 `i--`

遇到 `arr[i] > x` 时，代码会把它与右边的 `arr[last]` 交换。交换到 `i` 位置的新元素此前还没有被检查，不能直接让扫描指针跳过它。因此需要先执行 `i--`；随后 `for` 循环本身会执行一次 `i++`，两者抵消后，下一轮仍然检查同一个下标。

如果不执行这一步，交换进来的元素可能没有经过分类，最终就可能破坏三段区域的条件。

### 教练代码：三路划分优化

```cpp
struct QuickSort {
    vector<int> &arr;

    QuickSort(vector<int> &arr) : arr(arr) {
    }

    array<int, 2> partition(int l, int r, int x) {
        // first 左侧维护小于 x 的区域，last 右侧维护大于 x 的区域。
        int first = l, last = r;
        for (int i = l; i <= last; i++) {
            if (arr[i] < x)
                // 当前值属于左段，交换到 first 位置并扩大左段。
                swap(arr[i], arr[first++]);
            else if (arr[i] > x)
                // 右侧换回来的值还没有检查，i-- 用来抵消 for 的自增。
                swap(arr[i--], arr[last--]);
        }

        // [first, last] 就是所有等于 x 的元素组成的中段。
        return {first, last};
    }

    void quickSort(int l, int r) {
        // 区间至多一个元素时已经有序，不需要继续递归。
        if (l >= r)
            return;

        // 随机选择当前区间中的一个元素作为划分值。
        int x = arr[rand() % (r - l + 1) + l];
        array<int, 2> mid = partition(l, r, x);

        // 等于 x 的中段已经处理完，只递归左右两段。
        quickSort(l, mid[0] - 1);
        quickSort(mid[1] + 1, r);
    }
};
```

三路划分的关键收益是：当数组中有很多与 `x` 相等的元素时，这些元素会一次性进入中段，不会因为重复值而逐个进入后续递归。

## 时间复杂度和空间复杂度

以下复杂度主要按照优化后的三路随机快速排序讨论。

### 时间复杂度

随机快速排序的复杂度需要区分最好、最坏、理想划分和期望情况，不能只拿某一次随机结果代表所有运行情况。

- **最坏时间复杂度：`O(n^2)`。** 例如数组为 `[1，2，3，4，5，6]` 时，如果随机选择连续得到边界附近的划分值，每次都只能把问题规模减少很少，递归就会退化成近似一条链。随机化降低了这种情况持续发生的概率，但不能让最坏情况消失。
- **raw 笔记给出的最优示例：`O(n)`。** 当数组为 `[1，1，1，1，1，1]` 时，三路划分一次扫描就能把所有元素放入等于 `x` 的中段，左右两侧都为空，不再递归，因此这一层总工作量是线性的。
- **理想时间复杂度：`O(nlog n)`。** 如果每次都能把数组大致分成两半，递归树有 `O(log n)` 层，并且每层合计扫描 `O(n)` 个元素，所以总复杂度与归并排序相同。
- **期望时间复杂度：`O(nlog n)`。** 随机选择的行为不能直接按最好或最坏情况计算，而是通过期望和正态分布来进行分析。随机选择使划分长期平均地保持较好的平衡，因此随机快速排序通常按期望 `O(nlog n)` 讨论。

### 空间复杂度

三路 `partition` 是原地进行的，每次调用只使用 `first`、`last`、`i` 等常数个变量，单次划分的额外空间为 `O(1)`。额外空间主要来自递归调用栈：

- 在理想或期望的平衡划分下，递归深度为 `O(log n)`，因此空间复杂度按随机/期望口径为 `O(log n)`；
- 如果连续出现极不平衡的划分，递归深度可能达到 `O(n)`，对应的最坏额外空间复杂度也是 `O(n)`。

这里的空间复杂度只统计输入数组之外的空间，不把原数组本身计入额外空间。
