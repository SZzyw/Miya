# 二叉树及其三种序的递归实现

前置知识：[[算法讲解020【必备】递归和master公式]]、栈。

## 什么是二叉树

每个节点最多有两个子节点的图是二叉树。由于每个节点最多只有两个子节点，可以用 `array<int, 2>` 表示一个节点的孩子关系：`[0]` 存储左子树的节点编号，`[1]` 存储右子树的节点编号。

本页的代码使用节点编号表示节点，编号 `0` 表示不存在的子树。于是，遍历函数遇到 `0` 时就停止向下递归。

## 先序遍历

先序遍历的顺序是：**中 -> 左 -> 右**。也可以记成“根左右”：先访问当前节点，再遍历左子树，最后遍历右子树。

原笔记给出了一个 7 个节点的满二叉树示例。每个节点的两个数字分别表示左、右子节点，节点编号 `1` 是根节点，`0` 表示 `null`：

```text
节点：1  2  3  4  5  6  7
左子：2  4  6  0  0  0  0
右子：3  5  7  0  0  0  0
```

从根节点 `1` 开始，三种遍历的结果分别是：

- 先序：`1 2 4 5 3 6 7`
- 中序：`4 2 5 1 6 3 7`
- 后序：`4 5 2 6 7 3 1`

递归实现直接按照“中、左、右”的执行顺序书写：

```cpp
void preOrder(int head) {
    // 0 表示空子树；到达空节点时结束这一条递归路径。
    if (head == 0)
        return;

    // 先访问当前节点，再按左、右顺序递归两棵子树。
    cout << head << ' ';
    preOrder(tree[head][0]);
    preOrder(tree[head][1]);
}
```

### 先序遍历的栈实现

非递归写法需要用栈模拟递归调用。当前节点弹出后，由于“中”要最先执行，所以可以立即输出它。栈是后进先出，为了让左节点先被处理，需要**先推入右节点，再推入左节点**。

```cpp
void preOrder(int head) {
    stack<int> s;
    s.push(head);

    while (s.size()) {
        // 栈顶节点就是下一次要访问的节点。
        head = s.top();
        s.pop();
        cout << head << " ";

        // 右节点先入栈，左节点后入栈，出栈时才能保持左、右顺序。
        if (tree[head][1] != 0)
            s.push(tree[head][1]);
        if (tree[head][0] != 0)
            s.push(tree[head][0]);
    }
}
```

## 中序遍历

中序遍历的顺序是：**左 -> 中 -> 右**。也可以记成“左根右”：先遍历左子树，再访问当前节点，最后遍历右子树。

原笔记给出了一个 7 个节点的满二叉树示例。每个节点的两个数字分别表示左、右子节点，节点编号 `1` 是根节点，`0` 表示 `null`。上面的示例树的中序序列为 `4 2 5 1 6 3 7`，递归实现把输出语句放在左右两次递归调用之间：

```cpp
void inOrder(int head) {
    // 空子树没有节点可以访问。
    if (head == 0)
        return;

    // 先完成左子树，再输出当前节点，最后处理右子树。
    inOrder(tree[head][0]);
    cout << head << ' ';
    inOrder(tree[head][1]);
}
```

### 中序遍历的栈实现

中序遍历的关键是“先去左边，左边处理完后回来输出”。栈中保存沿当前子树左边界走过的节点，左边界走完后，从栈中弹出一个节点并打印；随后转向它的右子树，重复这一过程。

按原笔记的栈模拟方式，过程可以概括为：

1. 把子树头和它的左边界压入栈；
2. 弹出节点并打印；节点的右树进栈，再从新的子树头重复；
3. 没有子树且栈为空时，遍历结束。

```cpp
void inOrder(int head) {
    stack<int> s;
    s.push(head);

    while (s.size()) {
        head = s.top();
        s.pop();

        if (head == 0) {
            // 遇到空左子树时，栈顶保存的是刚刚走完左边界的节点。
            if (s.size()) {
                cout << s.top() << ' ';
                s.pop();
            }
            continue;
        }

        // 按“右、当前、左”的顺序压栈，弹出时就会先处理左子树。
        s.push(tree[head][1]);
        s.push(head);
        s.push(tree[head][0]);
    }
}
```

## 后序遍历

后序遍历的顺序是：**左 -> 右 -> 中**。也可以记成“左右根”：先遍历左子树，再遍历右子树，最后访问当前节点。

原笔记给出了一个 7 个节点的满二叉树示例。每个节点的两个数字分别表示左、右子节点，节点编号 `1` 是根节点，`0` 表示 `null`。上面的示例树的后序序列为 `4 5 2 6 7 3 1`，递归实现把输出语句放在两次递归调用之后：

```cpp
void posOrder(int head) {
    // 空子树没有节点可以访问。
    if (head == 0)
        return;

    // 先完成左右子树，最后才访问当前节点。
    posOrder(tree[head][0]);
    posOrder(tree[head][1]);
    cout << head << ' ';
}
```

### 后序遍历的栈实现

后序遍历中，当前节点不能在第一次到达时立即输出，因为必须确认左右子树都已经处理完。原笔记的判断依据是：**上次打印的节点一定是某个节点的左子树节点或右子树节点**。

- 如果上次打印的是当前节点的左子树节点，说明右子树还没有处理，应当转向右子树；
- 如果上次打印的是当前节点的右子树节点，说明左右子树都已经处理，应当打印当前节点。

代码用变量 `head` 记录上一次打印的节点，用栈顶 `cur` 表示当前正在判断的节点：

```cpp
void posOrder(int head) {
    stack<int> s;
    s.push(head);

    while (s.size()) {
        int cur = s.top();

        // 当前节点还有未处理的左子树，并且上一次打印的节点还不是它的孩子，先进入左子树。
        if (tree[cur][0] != 0 && head != tree[cur][0] && head != tree[cur][1])
            s.push(tree[cur][0]);
        // 左子树处理完后，如果右子树还没有处理，则进入右子树。
        else if (tree[cur][1] != 0 && head != tree[cur][1])
            s.push(tree[cur][1]);
        else {
            // 左右子树都处理完，当前节点才符合后序遍历的访问时机。
            cout << cur << ' ';
            head = cur;
            s.pop();
        }
    }
}
```

## 时间复杂度和空间复杂度

三种遍历都需要访问树中的每个节点一次，因此时间复杂度均为 `O(n)`。

递归实现使用系统栈，栈中同时存在的调用层数取决于树的高度，因此空间复杂度为树的高度。栈实现同样需要保存尚未处理的节点，辅助栈空间也与树的高度相关。
