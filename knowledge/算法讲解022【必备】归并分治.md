# 归并分治

前置知识：[[算法讲解020【必备】递归和master公式]]、[[算法讲解021【必备】归并排序]]

## 归并分治

归并分治要先观察一个问题在大范围上的答案，能不能拆成三部分：

1. 左部分内部产生的答案；
2. 右部分内部产生的答案；
3. 跨越左右两部分产生的答案。

接着再观察：在计算“跨越左右产生的答案”时，如果给左、右两部分都加上“各自有序”的设定，能不能获得计算上的便利性。

如果这两点都成立，那么这个问题很可能可以用归并分治解决。求解答案时，只需要把归并排序的过程加入进来：先让左、右部分各自有序，再利用有序性计算跨越左右产生的答案。

设当前处理的下标区间为 `[l, r]`，中点为 `m`，那么递归框架可以概括为：

```text
当前区间答案
= 左部分答案
+ 右部分答案
+ 跨越左右产生的答案
```

左、右部分的答案由递归调用解决；跨越左右的答案在 `merge` 中计算。`merge` 在统计答案的同时继续完成有序合并，这样更高层的递归就能继续使用“左右各自有序”的条件。

### 示例：`5，4，2，6，3，1`

原笔记给出的简略示例是：求每个 `v[i]` 左侧小于等于它的数之和。下面把它展开成完整的输入、计算过程和结论
#### 按定义计算每个位置的贡献

对每个 `v[i]`，只看它左侧下标小于 `i` 的元素，并把其中小于等于 `v[i]` 的数加起来：

| 下标 `i` | `v[i]` | 左侧满足 `v[j] <= v[i]` 的元素 |             当前贡献 |
| -----: | -----: | ----------------------- | ---------------: |
|      0 |      5 | 没有                      |                0 |
|      1 |      4 | 没有                      |                0 |
|      2 |      2 | 没有                      |                0 |
|      3 |      6 | 5、4、2                   | `5 + 4 + 2 = 11` |
|      4 |      3 | 2                       |                2 |
|      5 |      1 | 没有                      |                0 |

#### 归并分治过程

递归从整个下标区间 `[0, 5]` 开始，中点为 `2`，分成左区间 `[0, 2]` 和右区间 `[3, 5]`。继续递归，直到每个区间只剩一个元素。单元素区间没有两个不同位置可以组成贡献，因此内部答案都是 `0`。

回溯合并时，每一步都同时完成两件事：统计当前左右区间之间的跨区间贡献，并把当前区间整理为有序数组。

1. 合并 `[5]` 和 `[4]`：先取 `4`，左侧累计和为 `0`；再取 `5`。跨区间贡献为 `0`，得到 `[4, 5]`。
2. 合并 `[4, 5]` 和 `[2]`：先取 `2`，此时还没有可以结算的左侧贡献；随后取出 `4、5`。跨区间贡献为 `0`，得到 `[2, 4, 5]`。
3. 合并 `[6]` 和 `[3]`：先取 `3`，左侧累计和为 `0`；再取 `6`。跨区间贡献为 `0`，得到 `[3, 6]`。
4. 合并 `[3, 6]` 和 `[1]`：先取 `1`，左侧累计和为 `0`；随后取出 `3、6`。跨区间贡献为 `0`，得到 `[1, 3, 6]`。
5. 最后合并两个已经有序的区间 `[2, 4, 5]` 和 `[1, 3, 6]`：
   - 先比较 `2` 和 `1`，取右侧的 `1`，左侧累计和仍为 `0`，答案增加 `0`；
   - 比较 `2` 和 `3`，取左侧的 `2`，左侧累计和变为 `2`；
   - 比较 `4` 和 `3`，取右侧的 `3`，此时左侧已经取出的元素只有 `2`，答案增加 `2`；
   - 比较 `4` 和 `6`，取左侧的 `4`，左侧累计和变为 `2 + 4 = 6`；
   - 比较 `5` 和 `6`，取左侧的 `5`，左侧累计和变为 `6 + 5 = 11`；
   - 左侧已经取完，取出右侧的 `6`，答案增加当前左侧累计和 `11`。

最后一次合并的跨区间贡献为：

```text
2 + 11 = 13
```

合并结果为：

```text
[1, 2, 3, 4, 5, 6]
```

#### 输出与结论

```text
13
```

这个过程说明：归并分治不是只把数组排序，而是在递归统计左右内部答案的同时，利用左右区间有序这一条件，在 `merge` 中一次性统计跨区间答案。

## 时间复杂度和空间复杂度

整体递归框架按照归并排序分析。若 `merge` 对当前区间进行线性处理，那么递归深度为 `O(log n)`，每层合计处理 `O(n)` 个元素，整体时间复杂度为 `O(nlog n)`。

需要注意，归并分治的复杂度会根据 `merge` 的时间复杂度发生变化：不能只看“分成左右两部分”的递归形式，还要分析跨区间统计和合并本身是否能够在线性时间内完成。

使用普通归并合并时，辅助数组占用 `O(n)`，递归栈占用 `O(log n)`，完整代码的额外空间通常为 `O(n)`。
