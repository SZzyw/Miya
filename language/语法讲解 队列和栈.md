# 队列和栈

## 队列

队列的特点是**先进先出**，就像去食堂买饭排队：先到的人先打饭，后来的人排在队尾。

举例：`1` 进、`5` 进、`2` 进、出一个、出一个、`3` 进。

1. `1` 进队，队列是 `[1]`；
2. `5` 进队，队列是 `[1, 5]`；
3. `2` 进队，队列是 `[1, 5, 2]`；
4. 出一个，出的是队首 `1`，队列变成 `[5, 2]`；
5. 再出一个，出的是队首 `5`，队列变成 `[2]`；
6. `3` 进队，队列是 `[2, 3]`。

整个过程中，出队的永远是当前最早进来的那个元素。

### 循环队列

循环队列把队列的尾部和头部接起来：用一个定长数组加左右两个下标表示队列区间，下标走到数组末尾时绕回开头（和 [[语法讲解 双端队列]] 里循环数组的取模写法是同一套思路）。这样数组空间可以循环使用，出队时不需要搬动元素。

### 队列模板题

对应题目：[[洛谷-B3616-【模板】队列]]。

```cpp
struct Queue {
    vector<int> queue;
    int l, r;

    Queue(int n) {
        queue.resize(n);
        // l 指向队首，r 指向队尾；r = l - 1 表示区间为空。
        l = 0, r = -1;
    }

    void push(int x) {
        // 尾指针先右移，再写入。
        queue[++r] = x;
    }

    void pop() {
        // 出队只移动队首下标，不搬动数据。
        l++;
    }

    int size() {
        return r - l + 1;
    }

    int query() {
        return queue[l];
    }
};
```

入队、出队、取队首和求元素个数都是 `O(1)`。这份实现没有做成循环数组，而是把数组开到 `n + 10`，保证 `n` 次操作内最坏情况的入队次数也不会越界。

## 栈

栈的特点是**先进后出**，就像给弹夹压子弹：最后压进去的子弹最先被打出来。

举例：`1` 进、`5` 进、`2` 进、出一个、出一个、`3` 进。

1. `1` 进栈，栈是 `[1]`；
2. `5` 进栈，栈是 `[1, 5]`；
3. `2` 进栈，栈是 `[1, 5, 2]`；
4. 出一个，出的是栈顶 `2`，栈变成 `[1, 5]`；
5. 再出一个，出的是栈顶 `5`，栈变成 `[1]`；
6. `3` 进栈，栈是 `[1, 3]`。

栈的插入和删除都发生在同一端。

### 栈模板题

对应题目：[[洛谷-B3614-【模板】栈]]。raw 笔记特别提醒注意数据量。

```cpp
struct Stack {
    vector<int> stack;

    void push(int x) {
        stack.push_back(x);
    }

    void pop() {
        stack.pop_back();
    }

    int query() {
        return stack.back();
    }

    int size() {
        return stack.size();
    }
};
```

`vector` 的 `push_back` 和 `pop_back` 都作用在末尾，正好就是栈的同一端进出，所以栈不需要额外的下标。

数据规模方面：所有测试点的 `n` 之和不超过 `10^6`，并且元素满足 `0 <= x < 2^64`，所以 raw 的模板程序用 `#define int unsigned long long` 避免溢出，同时关闭同步流来加快大量读入。

## 例题

### 用栈实现队列

对应题目：[[LeetCode-232-用栈实现队列]]。

栈只能在同一端进出，队列要两端配合，所以用一个栈专门进、另一个栈专门出：需要出队时，如果 `out` 栈为空，就把 `in` 栈里的元素全部倒进 `out` 栈。元素倒一次顺序就反转，最早进 `in` 的元素会跑到 `out` 的栈顶，于是正好可以按先进先出的顺序弹出。

```cpp
class MyQueue {
public:
    stack<int> in, out;

    MyQueue() {
    }

    void push(int x) {
        in.push(x);
    }

    int pop() {
        // 只在出栈为空时搬运，保证每个元素最多被搬一次。
        if (out.size() == 0) {
            while (in.size()) {
                out.push(in.top());
                in.pop();
            }
        }
        int value = out.top();
        out.pop();
        return value;
    }

    int peek() {
        if (out.size() == 0) {
            while (in.size()) {
                out.push(in.top());
                in.pop();
            }
        }
        return out.top();
    }

    bool empty() {
        if (in.size() + out.size() > 0)
            return false;
        return true;
    }
};
```

`push` 是 `O(1)`；`pop`、`peek` 单次最坏是 `O(n)`，但每个元素从 `in` 搬到 `out` 只会发生一次，所以均摊下来仍是 `O(1)`，正好满足题目的进阶要求。

### 用队列实现栈

对应题目：[[LeetCode-225-用队列实现栈]]。

队列是先进先出，而栈顶元素在队尾。可以在取元素时把队首不断取出再放到队尾，循环 `size - 1` 次之后，最后进队的元素就转到了队首，这时它就是栈顶。

```cpp
class MyStack {
public:
    queue<int> que;

    MyStack() {
    }

    void push(int x) {
        que.push(x);
    }

    int pop() {
        // 把前 size - 1 个元素转到队尾，剩下的队首就是栈顶。
        int n = que.size() - 1;
        while (n--) {
            que.push(que.front());
            que.pop();
        }
        int value = que.front();
        que.pop();
        return value;
    }

    int top() {
        int n = que.size() - 1;
        while (n--) {
            que.push(que.front());
            que.pop();
        }
        int value = que.front();
        que.push(value); //记得放回去
        que.pop();
        return value;
    }

    bool empty() {
        if (que.size() > 0)
            return false;
        return true;
    }
};
```

`top` 比 `pop` 多了一步“放回去”：取出栈顶元素后，先把它的值推到队尾，再把原来队首的那一份弹掉，队列就恢复成原来的顺序，栈顶元素也没有被删除。

`push` 是 `O(1)`，`pop` 和 `top` 每次要旋转 `n - 1` 次，是 `O(n)`。题目还留了一个进阶：能否只用一个队列实现栈。

### 最小栈

对应题目：[[LeetCode-155-最小栈]]。

题目要求 `getMin` 也能在常数时间内完成，所以用一个辅助栈 `mmin` 记录“到目前为止的最小值”：主栈 `sta` 每压入一个值，辅助栈就压入 `min(mmin.top(), value)`。这样 `mmin` 的栈顶永远等于当前栈里的最小值。

```cpp
class MinStack {
public:
    stack<int> sta, mmin;

    MinStack() {
        // 先压入哨兵，避免在空栈上调用 top()。
        sta.push(INT_MAX);
        mmin.push(INT_MAX);
    }

    void push(int value) {
        sta.push(value);
        mmin.push(min(mmin.top(), value));
    }

    void pop() {
        sta.pop();
        mmin.pop();
    }

    int top() {
        return sta.top();
    }

    int getMin() {
        return mmin.top();
    }
};
```

`push`、`pop`、`top`、`getMin` 都是 `O(1)`，代价是额外使用了和主栈等长的 `O(n)` 空间。两个栈必须同步增删，否则 `mmin` 的栈顶就不再对应主栈当前的最小值。
