# 堆结构

## 完全二叉树

完全二叉树可以和数组的一段前缀一一对应，因此堆不需要真正的指针和节点，只用一个数组加上一个表示大小的变量就够了。设节点下标为 `i`：

- 父节点：`(i - 1) / 2`；
- 左孩子：`i * 2 + 1`；
- 右孩子：`i * 2 + 2`。

举例：`[3,5,3,6,2]`。

用下标关系把这五个数画出来：

```text
下标 0：3
├─ 左孩子 下标 1：5
│  ├─ 左孩子 下标 3：6
│  └─ 右孩子 下标 4：2
└─ 右孩子 下标 2：3
```

`0` 到 `4` 这段前缀刚好连续地填满了这棵树，中间没有空位，所以它是一个完全二叉树。堆使用的就是这样的前缀区间 `[0, size - 1]`，`size` 由单独的变量控制，而不是直接看数组长度。

## 堆（大根堆、小根堆）

在完全二叉树的基础上，如果始终保持每个节点都不小于它的孩子，这棵树就是**大根堆**；如果始终保持每个节点都不大于它的孩子，就是**小根堆**。

本页只讲大根堆，小根堆同理，把比较方向反过来即可。如果某个位置不满足要求，就通过下面两种调整把它修正。

### 向上调整

对于节点 `i`，如果它比父节点大，就和父节点交换，然后在新位置继续和新的父节点比较，直到不大于父节点或到达根节点为止。

举例：`[5,6,3,6]`。按自顶到底的顺序对每个位置做向上调整：

1. `i = 0`：它已经是根，`(0 - 1) / 2` 在 C++ 中等于 0，`arr[0] > arr[0]` 不成立，不调整。
2. `i = 1`：父节点下标 0，`6 > 5` 成立，交换后数组变成 `[6,5,3,6]`；`i` 变成 0，父节点还是自己，`6 > 6` 不成立，停止。
3. `i = 2`：父节点下标 0，`3 > 6` 不成立，不调整。
4. `i = 3`：父节点下标 1，`6 > 5` 成立，交换后数组变成 `[6,6,3,5]`；`i` 变成 1，父节点下标 0，`6 > 6` 不成立，停止。

调整结束后 `[6,6,3,5]` 就是一个大根堆。

```cpp
    void heapInsert(vector<int> &arr, int i) {
        while (arr[i] > arr[(i - 1) / 2]) { //-1/2为0
            swap(arr[i], arr[(i - 1) / 2]);
            i = (i - 1) / 2;
        }
    }
```

`i = 0` 时 `(0 - 1) / 2` 等于 `0`，判断变成 `arr[0] > arr[0]`，不成立，循环自然结束，所以不需要额外判断根节点。

### 向下调整

对于节点 `i`，如果它比孩子小，就和它交换，然后在新位置继续和新的孩子比较。注意要和**两个孩子中更大的那个**比较：只有换到更大的孩子上，这一层才可能满足“父节点不小于两个孩子”。

举例：`[6,6,5,3]`，把 `arr[0]` 改成 `2`，也就是数组变成 `[2,6,5,3]`，然后从下标 0 开始向下调整：

1. `i = 0`：左孩子下标 1 的 `6` 和右孩子下标 2 的 `5` 中，更大的是 `6`，所以候选是下标 1；`2 < 6`，交换后数组变成 `[6,2,5,3]`，`i` 变成 1。
2. `i = 1`：左孩子下标 3 的 `3`，右孩子下标 4 已经超出数组范围，候选是下标 3；`2 < 3`，交换后数组变成 `[6,3,5,2]`，`i` 变成 3。
3. `i = 3`：`2 * 3 + 1 = 7` 已经不小于区间长度 4，说明它是叶子，停止。

最后 `[6,3,5,2]` 重新满足大根堆的性质。

```cpp
    void heappify(vector<int> &arr, int i, int siz) {
        while ((i * 2 + 1) < siz) {
            // 先选出两个孩子中较大的一个。
            int l = i * 2 + 1, r = l + 1;
            int best = l;
            if (r < siz && arr[l] < arr[r])
                best = r;
            // 比这个孩子小就交换，然后继续往下检查。
            if (arr[i] < arr[best])
                swap(arr[i], arr[best]);
            else
                break;
            i = best;
        }
    }
```

第三个参数 `siz` 是当前堆的大小，不是数组长度：堆只占数组的一段前缀，调整不能越过这段前缀。循环条件 `(i * 2 + 1) < siz` 就是在判断“当前节点还有没有孩子”。

## 时间复杂度

无论是向上调整还是向下调整，每次调整最多走过的层数就是树的高度；数组长度为 `n` 时，完全二叉树的高度为 `O(log n)`。

因此，单次调整的时间复杂度为 `O(log n)`。

## 小根堆

小根堆和大根堆只差比较方向：向上调整时比父节点**小**就继续上浮，向下调整时选**较小**的孩子、比自己小就继续下沉。

[[洛谷-P3378-【模板】堆]] 要求维护数列中的最小值，用的就是小根堆：

```cpp
    void heapInsert(vector<int> &arr, int i) {
        while (arr[i] < arr[(i - 1) / 2]) {
            //-1/2为0
            swap(arr[i], arr[(i - 1) / 2]);
            i = (i - 1) / 2;
        }
    }

    void heappify(vector<int> &arr, int i, int siz) {
        while ((i * 2 + 1) < siz) {
            int l = i * 2 + 1, r = l + 1;
            int best = l;
            if (r < siz && arr[l] > arr[r])
                best = r;
            if (arr[i] > arr[best])
                swap(arr[i], arr[best]);
            else
                break;
            i = best;
        }
    }
```

删除最小值时，堆顶就是最小值：把它与当前堆的最后一个元素交换，堆的大小减 1（相当于把最小值弹出堆外），再从堆顶做一次向下调整，让新的堆顶沉到合适位置。
